Ejercicios: EDO - Métodos Avanzados de Primer Orden

MSc. Orlando Silva
Matemática II · PNF Electricidad · Trayecto I
Instrucciones. Resuelve cada una de las siguientes EDO mostrando claramente el procedimiento: identifica el tipo de ecuación, aplica el método correspondiente (factor integrante, sustitución, cambio de variable, etc.) y verifica la solución. Cuando se indique una condición inicial, determina la constante \(C\).

Dificultad: 🟢 Menor 🟡 Intermedio 🔴 Mayor
Las soluciones detalladas paso a paso están en soluciones.html (contraseña requerida). Puedes consultar la Teoría aquí.

A. EDO lineales de primer orden (factor integrante)

  1. 🟢 \(\dfrac{dy}{dx} + 2y = 4x\)
  2. 🟢 \(\dfrac{dy}{dx} - y = e^{2x}\)
  3. 🟢 \(x\dfrac{dy}{dx} + y = x^3\), \(x>0\)
  4. 🟡 \(\dfrac{dy}{dx} + y\cot x = \csc x\)
  5. 🟡 \(\dfrac{dy}{dx} - 3y = e^{2x}\)
  6. 🟡 \(x\dfrac{dy}{dx} + 2y = x^2\), \(x>0\)
  7. 🔴 \(\dfrac{dy}{dx} + \dfrac{2}{x}y = \dfrac{\sin x}{x^2}\), \(x>0\)
  8. 🔴 \(x\dfrac{dy}{dx} - y = x^2 e^x\), \(x>0\)

B. EDO homogéneas

  1. 🟢 \(y' = \dfrac{y}{x}\)
  2. 🟡 \(y' = \dfrac{y}{x} + 1\)
  3. 🟡 \(y' = \dfrac{x^2 + y^2}{xy}\)
  4. 🟡 \((x^2 + y^2)\,dx - xy\,dy = 0\)
  5. 🔴 \(y' = \dfrac{y^2 + xy}{x^2}\)
  6. 🔴 \(y' = \dfrac{x+y}{x-y}\)
  7. 🔴 \((x^2 - y^2)\,dx + 2xy\,dy = 0\)

C. Factores integrantes

  1. 🟡 \((2y)\,dx + (x)\,dy = 0\)
  2. 🟡 \((y)\,dx + (2x + y^2)\,dy = 0\)
  3. 🟡 \((y - x)\,dx + (y + x)\,dy = 0\)
  4. 🔴 \((3x^2 y + 2xy + y^3)\,dx + (x^2 + y^2)\,dy = 0\)
  5. 🔴 \((x^2 y + y)\,dx + (x - x^3)\,dy = 0\)
  6. 🔴 \((x + y)\,dx + (x\ln x)\,dy = 0\), \(x>0\)
  7. 🔴 \((2xy^2 + 2y)\,dx + (2x^2 y + 2x)\,dy = 0\)

D. Ecuaciones de Bernoulli y Riccati

  1. 🟡 \(y' + y = xy^2\)
  2. 🟡 \(y' + \dfrac{1}{x}y = y^2\), \(x>0\)
  3. 🟡 \(y' + 2xy = 2xy^3\)
  4. 🟡 \(y' - y = y^3\)
  5. 🔴 \(y' + \dfrac{2}{x}y = 3y^2\), \(x>0\)
  6. 🔴 \(y' + y = e^x y^2\)
  7. 🔴 \(y' = 1 - y^2\), con \(y_1=1\) solución particular (Riccati)
  8. 🔴 \(y' = y^2 - y - 2\), con \(y_1=2\) solución particular (Riccati)
  9. 🔴 \(y' = \dfrac{1}{x} - y + y^2\), con \(y_1=1\) solución particular (Riccati)

E. Ecuaciones de Lagrange y Clairaut

  1. 🟡 \(y = xy' + (y')^2\) (Clairaut)
  2. 🟡 \(y = xy' + \dfrac{1}{y'}\) (Clairaut)
  3. 🟡 \(y = xy' + \sqrt{1+(y')^2}\) (Clairaut)
  4. 🔴 \(y = 2xy' + (y')^2\) (Lagrange)
  5. 🔴 \(y = x(y')^2 + (y')^2\) (Lagrange)
  6. 🔴 \(y = x\left(y' + \dfrac{1}{y'}\right)\) (Lagrange)

F. Aplicaciones: RL, RC, mezclas y enfriamiento

  1. 🟢 Un circuito RL con \(L=2\) H, \(R=4\ \Omega\), \(V=12\) V constante. Encuentra \(i(t)\) si \(i(0)=0\).
  2. 🟡 Un circuito RL con \(L=0.5\) H, \(R=2\ \Omega\), \(V=10\) V constante. Encuentra \(i(t)\) si \(i(0)=0\).
  3. 🟡 Un circuito RC con \(R=10\ \Omega\), \(C=0.01\) F, \(V=5\) V constante. Encuentra \(v_C(t)\) si \(v_C(0)=0\).
  4. 🟡 Un circuito RC con \(R=100\ \Omega\), \(C=0.001\) F, \(V(t)=10\) V constante. Encuentra \(v_C(t)\) si \(v_C(0)=2\) V.
  5. 🔴 Un tanque contiene 100 L de agua. Entra salmuera a 2 L/min con 0.1 kg/L, y la mezcla sale a 2 L/min. Si \(Q(0)=0\), encuentra \(Q(t)\) y la concentración a largo plazo.
  6. 🔴 Un tanque contiene 50 L de agua con 5 kg de sal disueltos. Entra agua pura a 3 L/min y sale la mezcla a 3 L/min. Encuentra \(Q(t)\) y el tiempo en que la sal se reduce a 1 kg.
  7. 🔴 Un cuerpo a \(90°C\) se enfría en un ambiente a \(20°C\). Si la temperatura a los 10 min es \(60°C\), halla la constante \(k\) y \(T(t)\).
  8. 🔴 Un cuerpo a \(100°C\) se enfría en un ambiente a \(25°C\). Si \(k=0.05\ \text{min}^{-1}\), ¿cuánto tarda en llegar a \(50°C\)?
  9. 🔴 Un circuito RL con \(L=1\) H, \(R=2\ \Omega\), \(V(t)=10\sin(2t)\) V. Encuentra la solución general para \(i(t)\).
