A. EDO lineales de primer orden (factor integrante)

Ejercicio 1. \(y' + 2y = 4x\)
Paso 1. \(P(x)=2 \Rightarrow \mu=e^{\int 2\,dx}=e^{2x}\).
Paso 2. Multiplicando: \(e^{2x}y'+2e^{2x}y=4xe^{2x} \Rightarrow (e^{2x}y)'=4xe^{2x}\).
Paso 3. Integrando por partes: \(e^{2x}y=2xe^{2x}-e^{2x}+C\).
\(y = 2x - 1 + Ce^{-2x}\).
Ejercicio 2. \(y' - y = e^{2x}\)
Paso 1. \(P(x)=-1 \Rightarrow \mu=e^{-x}\).
Paso 2. \((e^{-x}y)'=e^{-x}\cdot e^{2x}=e^{x}\).
Paso 3. Integrando: \(e^{-x}y=e^{x}+C\).
\(y = e^{2x} + Ce^{x}\).
Ejercicio 3. \(xy' + y = x^3\), \(x>0\)
Paso 1. Dividiendo entre \(x\): \(y'+\frac1x y=x^2\). \(\mu=e^{\ln x}=x\).
Paso 2. \((xy)'=x^3 \Rightarrow xy=\frac14 x^4+C\).
\(y = \frac14 x^3 + \frac{C}{x}\).
Ejercicio 4. \(y' + y\cot x = \csc x\)
Paso 1. \(P=\cot x \Rightarrow \mu=e^{\int \cot x\,dx}=e^{\ln|\sin x|}=\sin x\).
Paso 2. \((\sin x\,y)'=\sin x\csc x=1 \Rightarrow \sin x\,y=x+C\).
\(y = \frac{x+C}{\sin x}\).
Ejercicio 5. \(y' - 3y = e^{2x}\)
Paso 1. \(\mu=e^{-3x}\).
Paso 2. \((e^{-3x}y)'=e^{-3x}e^{2x}=e^{-x} \Rightarrow e^{-3x}y=-e^{-x}+C\).
\(y = -e^{2x} + Ce^{3x}\).
Ejercicio 6. \(xy' + 2y = x^2\), \(x>0\)
Paso 1. Dividiendo: \(y'+\frac2x y=x\). \(\mu=e^{2\ln x}=x^2\).
Paso 2. \((x^2y)'=x^3 \Rightarrow x^2y=\frac14 x^4+C\).
\(y = \frac14 x^2 + \frac{C}{x^2}\).
Ejercicio 7. \(y' + \frac{2}{x}y = \frac{\sin x}{x^2}\), \(x>0\)
Paso 1. \(\mu=e^{2\ln x}=x^2\).
Paso 2. \((x^2y)'=\sin x \Rightarrow x^2y=-\cos x+C\).
\(y = \frac{C-\cos x}{x^2}\).
Ejercicio 8. \(xy' - y = x^2e^x\), \(x>0\)
Paso 1. Dividiendo: \(y'-\frac1x y=xe^x\). \(\mu=e^{-\ln x}=\frac1x\).
Paso 2. \((\frac{y}{x})'=e^x \Rightarrow \frac{y}{x}=e^x+C\).
\(y = x e^x + Cx\).

B. EDO homogéneas

Ejercicio 9. \(y' = \frac{y}{x}\)
Paso 1. \(y=vx\), \(y'=v+xv'\).
Paso 2. \(v+xv'=v \Rightarrow xv'=0 \Rightarrow v=C\).
\(y = Cx\).
Ejercicio 10. \(y' = \frac{y}{x} + 1\)
Paso 1. \(y=vx\), \(y'=v+xv'\).
Paso 2. \(v+xv'=v+1 \Rightarrow xv'=1 \Rightarrow v=\ln|x|+C\).
\(y = x\ln|x| + Cx\).
Ejercicio 11. \(y' = \frac{x^2+y^2}{xy}\)
Paso 1. \(y'=\frac{x}{y}+\frac{y}{x}=\frac1v+v\).
Paso 2. \(v+xv'=v+\frac1v \Rightarrow xv'=\frac1v \Rightarrow v\,dv=\frac{dx}{x}\).
Paso 3. \(\frac12 v^2=\ln|x|+C \Rightarrow v^2=2\ln|x|+C\).
\(y^2 = 2x^2\ln|x| + Cx^2\).
Ejercicio 12. \((x^2+y^2)dx - xy\,dy=0\)
Paso 1. \(y'=\frac{x^2+y^2}{xy}\), mismo caso que el Ej. 11.
\(y^2 = 2x^2\ln|x| + Cx^2\).
Ejercicio 13. \(y' = \frac{y^2+xy}{x^2}\)
Paso 1. \(y'=\left(\frac{y}{x}\right)^2+\frac{y}{x}=v^2+v\).
Paso 2. \(v+xv'=v^2+v \Rightarrow xv'=v^2 \Rightarrow \frac{dv}{v^2}=\frac{dx}{x}\).
Paso 3. \(-\frac1v=\ln|x|+C \Rightarrow v=-\frac{1}{\ln|x|+C}\).
\(y = -\frac{x}{\ln|x|+C}\).
Ejercicio 14. \(y' = \frac{x+y}{x-y}\)
Paso 1. \(y'=\frac{1+v}{1-v}\).
Paso 2. \(v+xv'=\frac{1+v}{1-v} \Rightarrow xv'=\frac{1+v}{1-v}-v=\frac{1+v^2}{1-v}\).
Paso 3. \(\frac{1-v}{1+v^2}dv=\frac{dx}{x} \Rightarrow \arctan v-\frac12\ln(1+v^2)=\ln|x|+C\).
\(\arctan\frac{y}{x}-\frac12\ln\left(1+\frac{y^2}{x^2}\right)=\ln|x|+C\).
Ejercicio 15. \((x^2-y^2)dx + 2xy\,dy=0\)
Paso 1. \(y'=\frac{y^2-x^2}{2xy}=\frac{v^2-1}{2v}\).
Paso 2. \(v+xv'=\frac{v^2-1}{2v} \Rightarrow xv'=\frac{v^2-1}{2v}-v=\frac{-v^2-1}{2v}\).
Paso 3. \(-\frac{2v}{v^2+1}dv=\frac{dx}{x} \Rightarrow -\ln(v^2+1)=\ln|x|+C\).
\(x^2+y^2=Cx\).

C. Factores integrantes

Ejercicio 16. \((2y)dx + (x)dy=0\)
Paso 1. \(M=2y\), \(N=x\). \(\partial_yM=2\), \(\partial_xN=1\), no exacta.
Paso 2. \(\frac{\partial_yM-\partial_xN}{N}=\frac{2-1}{x}=\frac1x=f(x)\). \(\mu=e^{\int \frac1x dx}=x\).
Paso 3. Multiplicando: \(2xy\,dx+x^2\,dy=0\), exacta. \(F=x^2y\).
\(x^2y = C\).
Ejercicio 17. \((y)dx + (2x+y^2)dy=0\)
Paso 1. \(M=y\), \(N=2x+y^2\). \(\partial_yM=1\), \(\partial_xN=2\), no exacta.
Paso 2. \(\frac{\partial_xN-\partial_yM}{M}=\frac{2-1}{y}=\frac1y=g(y)\). \(\mu=e^{\int \frac1y dy}=y\).
Paso 3. Multiplicando: \(y^2\,dx+(2xy+y^3)\,dy=0\), exacta. \(F=xy^2+\frac14 y^4\).
\(xy^2+\frac14 y^4 = C\).
Ejercicio 18. \((y-x)dx + (y+x)dy=0\)
Paso 1. \(M=y-x\), \(N=y+x\). \(\partial_yM=1\), \(\partial_xN=1\). Es exacta (revisión: \(\partial_yM=\partial_xN=1\)).
Paso 2. \(F=\int(y-x)dx=\frac12 y^2-xy\)... integrando \(M\) respecto de \(x\): \(F=xy-\frac12 x^2+g(y)\). Derivando respecto de \(y\): \(x+g'(y)=y+x \Rightarrow g'(y)=y \Rightarrow g=\frac12 y^2\).
\(xy-\frac12 x^2+\frac12 y^2 = C\), o \(y^2-x^2+2xy=C\).
Ejercicio 19. \((3x^2y+2xy+y^3)dx + (x^2+y^2)dy=0\)
Paso 1. \(\partial_yM=3x^2+2x+3y^2\), \(\partial_xN=2x\). No exacta.
Paso 2. \(\frac{\partial_yM-\partial_xN}{N}=\frac{3x^2+3y^2}{x^2+y^2}=3=f(x)\). \(\mu=e^{3x}\).
Paso 3. Multiplicando y resolviendo (exacta): \(F=e^{3x}(x^2y+\frac13 y^3)+C\).
\(e^{3x}\left(x^2y+\frac13 y^3\right)=C\).
Ejercicio 20. \((x^2y+y)dx + (x-x^3)dy=0\)
Paso 1. \(M=y(x^2+1)\), \(N=x(1-x^2)\). \(\partial_yM=x^2+1\), \(\partial_xN=1-3x^2\). No exacta.
Paso 2. \(\frac{\partial_yM-\partial_xN}{N}=\frac{x^2+1-1+3x^2}{x(1-x^2)}=\frac{4x^2}{x(1-x^2)}=\frac{4x}{1-x^2}=f(x)\). \(\mu=e^{\int \frac{4x}{1-x^2}dx}=e^{-2\ln|1-x^2|}=\frac{1}{(1-x^2)^2}\).
Paso 3. Multiplicando: \(\frac{y(x^2+1)}{(1-x^2)^2}dx+\frac{x}{1-x^2}dy=0\), exacta. \(F=\frac{xy}{1-x^2}\).
\(\frac{xy}{1-x^2}=C\).
Ejercicio 21. \((x+y)dx + (x\ln x)dy=0\), \(x>0\)
Paso 1. \(M=x+y\), \(N=x\ln x\). \(\partial_yM=1\), \(\partial_xN=\ln x+1\). No exacta.
Paso 2. \(\frac{\partial_yM-\partial_xN}{N}=\frac{1-(\ln x+1)}{x\ln x}=\frac{-\ln x}{x\ln x}=-\frac1x=f(x)\). \(\mu=e^{-\ln x}=\frac1x\).
Paso 3. Multiplicando: \((1+\frac{y}{x})dx+(\ln x)dy=0\), exacta. \(F=x+y\ln x\).
\(x+y\ln x=C\).
Ejercicio 22. \((2xy^2+2y)dx + (2x^2y+2x)dy=0\)
Paso 1. \(M=2y(xy+1)\), \(N=2x(xy+1)\). \(\partial_yM=4xy+2\), \(\partial_xN=4xy+2\). Es exacta.
Paso 2. \(F=\int(2xy^2+2y)dx=x^2y^2+2xy+g(y)\). Derivando respecto de \(y\): \(2x^2y+2x+g'(y)=2x^2y+2x \Rightarrow g'=0\).
\(x^2y^2+2xy = C\), o \(xy(xy+2)=C\).

D. Ecuaciones de Bernoulli y Riccati

Ejercicio 23. \(y'+y=xy^2\)
Paso 1. \(n=2\), \(z=y^{-1}\), \(z'=-y^{-2}y'\). Multiplicando por \(-y^{-2}\): \(z'-z=-x\).
Paso 2. \(\mu=e^{-x}\): \((e^{-x}z)'=-xe^{-x} \Rightarrow e^{-x}z=e^{-x}(x+1)+C \Rightarrow z=x+1+Ce^x\).
\(y = \dfrac{1}{x+1+Ce^x}\).
Ejercicio 24. \(y'+\frac1x y=y^2\), \(x>0\)
Paso 1. \(n=2\), \(z=y^{-1}\). Multiplicando por \(-y^{-2}\): \(z'-\frac1x z=-1\).
Paso 2. \(\mu=\frac1x\): \((\frac{z}{x})'=-\frac1x \Rightarrow \frac{z}{x}=-\ln x+C \Rightarrow z=x(C-\ln x)\).
\(y = \dfrac{1}{x(C-\ln x)}\).
Ejercicio 25. \(y'+2xy=2xy^3\)
Paso 1. \(n=3\), \(z=y^{-2}\), \(z'=-2y^{-3}y'\). Multiplicando por \(-2y^{-3}\): \(z'-4xz=-4x\).
Paso 2. \(\mu=e^{-2x^2}\): \((e^{-2x^2}z)'=-4xe^{-2x^2} \Rightarrow z=2+Ce^{2x^2}\).
\(y = \dfrac{1}{\sqrt{2+Ce^{2x^2}}}\).
Ejercicio 26. \(y'-y=y^3\)
Paso 1. \(n=3\), \(z=y^{-2}\), \(z'=-2y^{-3}y'\). Multiplicando por \(-2y^{-3}\): \(z'+2z=-2\).
Paso 2. \(\mu=e^{2x}\): \((e^{2x}z)'=-2e^{2x} \Rightarrow e^{2x}z=-e^{2x}+C \Rightarrow z=-1+Ce^{-2x}\).
\(y = \dfrac{1}{\sqrt{-1+Ce^{-2x}}}\).
Ejercicio 27. \(y'+\frac2x y=3y^2\), \(x>0\)
Paso 1. \(n=2\), \(z=y^{-1}\). Multiplicando por \(-y^{-2}\): \(z'-\frac2x z=-3\).
Paso 2. \(\mu=\frac{1}{x^2}\): \((\frac{z}{x^2})'=-\frac{3}{x^2} \Rightarrow \frac{z}{x^2}=\frac3x+C \Rightarrow z=3x+Cx^2\).
\(y = \dfrac{1}{3x+Cx^2}\).
Ejercicio 28. \(y'+y=e^x y^2\)
Paso 1. \(n=2\), \(z=y^{-1}\). Multiplicando por \(-y^{-2}\): \(z'-z=-e^x\).
Paso 2. \(\mu=e^{-x}\): \((e^{-x}z)'=-1 \Rightarrow e^{-x}z=-x+C \Rightarrow z=e^x(C-x)\).
\(y = \dfrac{e^{-x}}{C-x}\).
Ejercicio 29. \(y'=1-y^2\), \(y_1=1\) (Riccati)
Paso 1. Verificación: \(y_1'=0=1-1^2\) ✓. \(y=1+\frac1v\), \(y'=-\frac{v'}{v^2}\).
Paso 2. \(-\frac{v'}{v^2}=1-(1+\frac1v)^2=-\frac{2}{v}-\frac{1}{v^2} \Rightarrow v'=2v+1 \Rightarrow v'-2v=1\).
Paso 3. \(\mu=e^{-2x}\): \(v=-\frac12+Ce^{2x}\).
\(y = 1+\dfrac{1}{-\frac12+Ce^{2x}}\).
Ejercicio 30. \(y'=y^2-y-2\), \(y_1=2\) (Riccati)
Paso 1. Verificación: \(y_1'=0=4-2-2\) ✓. \(y=2+\frac1v\), \(y'=-\frac{v'}{v^2}\).
Paso 2. \(-\frac{v'}{v^2}=(2+\frac1v)^2-(2+\frac1v)-2=\frac{3}{v}+\frac{1}{v^2} \Rightarrow v'=-3v-1\).
Paso 3. \(\mu=e^{3x}\): \(v=-\frac13+Ce^{-3x}\).
\(y = 2+\dfrac{1}{-\frac13+Ce^{-3x}}\).
Ejercicio 31. \(y'=\frac1x-y+y^2\), \(y_1=1\) (Riccati)
Paso 1. Verificación: \(y_1'=0\), \(\frac1x-1+1=\frac1x\). No es solución. Corrección: con \(y_1=1\), \(y'=y^2-y\) (sin el \(1/x\)), sí funciona. Pero como está planteado, \(y_1=1\) no es solución particular. Se deja como ejercicio para discutir en clase: si se propone \(y_1=1/x\), se verifica: \(y_1'=-1/x^2\), y \(\frac1x-\frac1x+\frac{1}{x^2}=\frac{1}{x^2}\)... tampoco. La ecuación no tiene solución particular elemental \(y_1=1\); se requiere resolver por otro método o proponer otra \(y_1\).
Nota. Este ejercicio ilustra que en Riccati la solución particular debe verificarse siempre. Si no se dispone de una, no se puede aplicar el método directo.

E. Ecuaciones de Lagrange y Clairaut

Ejercicio 32. \(y=xy'+(y')^2\) (Clairaut)
Paso 1. \(p=y'\), \(y=xp+p^2\). Derivando: \(p=p+xp'+2pp' \Rightarrow p'(x+2p)=0\).
Paso 2. \(p'=0 \Rightarrow p=C \Rightarrow y=Cx+C^2\) (general). \(x+2p=0 \Rightarrow p=-x/2 \Rightarrow y=-x^2/4\) (singular).
General: \(y=Cx+C^2\). Singular: \(y=-x^2/4\).
Ejercicio 33. \(y=xy'+\frac{1}{y'}\) (Clairaut)
Paso 1. \(y=xp+\frac1p\). Derivando: \(p=p+xp'-\frac{p'}{p^2} \Rightarrow p'(x-\frac{1}{p^2})=0\).
Paso 2. \(p'=0 \Rightarrow p=C \Rightarrow y=Cx+\frac1C\). Singular: \(x=\frac{1}{p^2} \Rightarrow p=\pm\frac{1}{\sqrt x} \Rightarrow y=\pm\sqrt x+\frac{1}{\pm 1/\sqrt x}=\pm 2\sqrt x\).
General: \(y=Cx+\frac1C\). Singular: \(y=\pm 2\sqrt x\).
Ejercicio 34. \(y=xy'+\sqrt{1+(y')^2}\) (Clairaut)
Paso 1. \(y=xp+\sqrt{1+p^2}\). Derivando: \(p=p+xp'+\frac{p}{\sqrt{1+p^2}}p' \Rightarrow p'(x+\frac{p}{\sqrt{1+p^2}})=0\).
Paso 2. General: \(p=C \Rightarrow y=Cx+\sqrt{1+C^2}\). Singular: \(x=-\frac{p}{\sqrt{1+p^2}}\), junto con \(y=xp+\sqrt{1+p^2}\) da \(x^2+y^2=1\) (circunferencia).
General: \(y=Cx+\sqrt{1+C^2}\). Singular: \(x^2+y^2=1\).
Ejercicio 35. \(y=2xy'+(y')^2\) (Lagrange)
Paso 1. \(y=2xp+p^2\). Derivando: \(p=2p+2xp'+2pp' \Rightarrow -p=2(x+p)p'\).
Paso 2. \(\frac{dx}{dp}=-\frac{2(x+p)}{p}=-\frac2p x-2\). Lineal en \(x(p)\): \(\mu=p^2\): \((p^2x)'=-2p^2 \Rightarrow x=-\frac23 p+\frac{C}{p^2}\).
Paso 3. Sustituyendo en \(y=2xp+p^2\): \(y=-\frac13 p^2+\frac{2C}{p}\).
Solución paramétrica: \(x=-\frac23 p+\frac{C}{p^2}\), \(y=-\frac13 p^2+\frac{2C}{p}\).
Ejercicio 36. \(y=x(y')^2+(y')^2\) (Lagrange)
Paso 1. \(y=xp^2+p^2=p^2(x+1)\). Derivando: \(p=2p(x+1)p'+p^2 \Rightarrow p-p^2=2p(x+1)p'\).
Paso 2. \(\frac{dx}{dp}=\frac{2(x+1)}{p-1}\)... resolviendo: \(x+1=C(p-1)^2-\frac{p^2}{2}-p\)... se obtiene la paramétrica.
Solución paramétrica (se deja en forma implícita): \(x+1=C(p-1)^2-\frac{p^2}{2}-p\), \(y=p^2(x+1)\).
Ejercicio 37. \(y=x\left(y'+\frac{1}{y'}\right)\) (Lagrange)
Paso 1. \(y=x(p+\frac1p)\). Derivando: \(p=p+\frac1p+x(1-\frac{1}{p^2})p' \Rightarrow -\frac1p=x(1-\frac{1}{p^2})p'\).
Paso 2. \(\frac{dx}{dp}=-\frac{x(1-1/p^2)}{1/p}=-xp+\frac{x}{p}\)... se resuelve como lineal en \(x(p)\).
Solución paramétrica: \(x=\frac{C}{p}e^{-p^2/2}\)... (se deja en forma paramétrica).

F. Aplicaciones: RL, RC, mezclas y enfriamiento

Ejercicio 38. RL: \(L=2\), \(R=4\), \(V=12\), \(i(0)=0\)
Paso 1. \(2i'+4i=12 \Rightarrow i'+2i=6\). \(\mu=e^{2t}\).
Paso 2. \((e^{2t}i)'=6e^{2t} \Rightarrow e^{2t}i=3e^{2t}+C \Rightarrow i=3+Ce^{-2t}\).
Paso 3. \(i(0)=0 \Rightarrow 3+C=0 \Rightarrow C=-3\).
\(i(t)=3(1-e^{-2t})\) A.
Ejercicio 39. RL: \(L=0.5\), \(R=2\), \(V=10\), \(i(0)=0\)
Paso 1. \(0.5i'+2i=10 \Rightarrow i'+4i=20\). \(\mu=e^{4t}\).
Paso 2. \(i=5+Ce^{-4t}\). \(i(0)=0 \Rightarrow C=-5\).
\(i(t)=5(1-e^{-4t})\) A.
Ejercicio 40. RC: \(R=10\), \(C=0.01\), \(V=5\), \(v_C(0)=0\)
Paso 1. \(RC=0.1\). \(0.1v_C'+v_C=5 \Rightarrow v_C'+10v_C=50\). \(\mu=e^{10t}\).
Paso 2. \(v_C=5+Ce^{-10t}\). \(v_C(0)=0 \Rightarrow C=-5\).
\(v_C(t)=5(1-e^{-10t})\) V.
Ejercicio 41. RC: \(R=100\), \(C=0.001\), \(V=10\), \(v_C(0)=2\)
Paso 1. \(RC=0.1\). \(v_C'+10v_C=100\). \(\mu=e^{10t}\).
Paso 2. \(v_C=10+Ce^{-10t}\). \(v_C(0)=2 \Rightarrow C=-8\).
\(v_C(t)=10-8e^{-10t}\) V.
Ejercicio 42. Mezcla: \(V=100\) L, \(r_{in}=2\) L/min, \(c_{in}=0.1\) kg/L, \(r_{out}=2\) L/min, \(Q(0)=0\)
Paso 1. \(Q'=0.2-0.02Q \Rightarrow Q'+0.02Q=0.2\). \(\mu=e^{0.02t}\).
Paso 2. \(Q=10+Ce^{-0.02t}\). \(Q(0)=0 \Rightarrow C=-10\).
\(Q(t)=10(1-e^{-0.02t})\) kg. Concentración a largo plazo: \(0.1\) kg/L.
Ejercicio 43. Mezcla: \(V=50\) L, \(Q(0)=5\) kg, entra agua pura a 3 L/min, sale a 3 L/min
Paso 1. \(Q'=-\frac{3}{50}Q \Rightarrow Q=Ce^{-0.06t}\).
Paso 2. \(Q(0)=5 \Rightarrow C=5\). \(Q(t)=5e^{-0.06t}\). Para \(Q=1\): \(1=5e^{-0.06t} \Rightarrow t=\frac{\ln 5}{0.06}\approx 26.8\) min.
\(Q(t)=5e^{-0.06t}\) kg. Tiempo para 1 kg: \(\approx 26.8\) min.
Ejercicio 44. Enfriamiento: \(T(0)=90°C\), \(T_m=20°C\), \(T(10)=60°C\)
Paso 1. \(T'=-k(T-20) \Rightarrow T-20=Ce^{-kt}\). \(T(0)=90 \Rightarrow C=70\).
Paso 2. \(T(10)=60 \Rightarrow 40=70e^{-10k} \Rightarrow e^{-10k}=\frac47 \Rightarrow k=\frac{1}{10}\ln\frac74\approx 0.0559\).
\(k\approx 0.0559\ \text{min}^{-1}\), \(T(t)=20+70e^{-0.0559t}\).
Ejercicio 45. Enfriamiento: \(T(0)=100°C\), \(T_m=25°C\), \(k=0.05\), \(T(t)=50°C\)
Paso 1. \(T-25=75e^{-0.05t}\).
Paso 2. \(50-25=75e^{-0.05t} \Rightarrow 25=75e^{-0.05t} \Rightarrow e^{-0.05t}=\frac13 \Rightarrow t=\frac{\ln 3}{0.05}\approx 21.97\).
\(t\approx 22\) min.

📝 Soluciones - Pre-parciales

Pre-parcial Tipo A
1. (Lineal) \(y'+2y=4x\). \(\mu=e^{2x}\). \((e^{2x}y)'=4xe^{2x} \Rightarrow y=2x-1+Ce^{-2x}\).
2. (Homogénea) \(y'=y/x+1\). \(y=vx \Rightarrow v+xv'=v+1 \Rightarrow v=\ln|x|+C\). \(y=x\ln|x|+Cx\).
3. (Factor integrante) \((2y)dx+(x)dy=0\). \(\mu=x\). \(2xy\,dx+x^2\,dy=0 \Rightarrow x^2y=C\).
4. (Bernoulli) \(y'+y=xy^2\). \(z=y^{-1}\), \(z'-z=-x\), \(\mu=e^{-x}\). \(z=x+1+Ce^x\). \(y=1/(x+1+Ce^x)\).
5. (PVI) \(y'+2y=4x\), \(y(0)=1\). Del Ej. 1: \(y=2x-1+Ce^{-2x}\). \(y(0)=1 \Rightarrow C=2\).
\(y=2x-1+2e^{-2x}\).
Pre-parcial Tipo B
1. (Lineal) \(y'-3y=e^{2x}\). \(\mu=e^{-3x}\). \((e^{-3x}y)'=e^{-x} \Rightarrow y=-e^{2x}+Ce^{3x}\).
2. (Homogénea) \(y'=(x^2+y^2)/(xy)\). \(y=vx \Rightarrow v+xv'=v+1/v \Rightarrow v^2=2\ln|x|+C\). \(y^2=2x^2\ln|x|+Cx^2\).
3. (Factor integrante) \((y)dx+(2x+y^2)dy=0\). \(\mu=y\). \(y^2dx+(2xy+y^3)dy=0 \Rightarrow xy^2+\frac14 y^4=C\).
4. (Bernoulli) \(y'+\frac1x y=y^2\). \(z=y^{-1}\), \(z'-\frac1x z=-1\), \(\mu=1/x\). \(z=x(C-\ln x)\). \(y=1/[x(C-\ln x)]\).
5. (PVI) \(y'+y=xy^2\), \(y(0)=1\). Del Ej. 23: \(y=1/(x+1+Ce^x)\). \(y(0)=1 \Rightarrow C=0\).
\(y=1/(x+1)\).
