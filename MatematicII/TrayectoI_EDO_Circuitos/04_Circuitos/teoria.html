1. Elementos básicos de circuitos

Resistor (R): \(v_R = R i\) (Ley de Ohm)
Inductor (L): \(v_L = L \frac{di}{dt}\)
Capacitor (C): \(i_C = C \frac{dv_C}{dt}\) o \(v_C = \frac{1}{C}\int i_C dt\)

2. Circuito RC (Resistor-Capacitor)

Un circuito RC serie satisface: \[ RC \frac{dv_C}{dt} + v_C = v(t) \] donde \(v_C(t)\) es la tensión en el capacitor.

2.1 Respuesta a escalón (\(v(t) = V_0\) constante)

La solución general es: \[ v_C(t) = V_0 + C e^{-t/(RC)} \] Con condición inicial \(v_C(0) = 0\): \[ v_C(t) = V_0(1 - e^{-t/(RC)}) \] La corriente es: \[ i(t) = \frac{V_0}{R} e^{-t/(RC)} \]
Circuito RC con \(R=10\ \Omega\), \(C=0.01\) F, \(V_0=5\) V:
\(v_C(t) = 5(1 - e^{-10t})\) V.
\(i(t) = 0.5 e^{-10t}\) A.

2.2 Respuesta natural (descarga)

Si el capacitor tiene carga inicial \(v_C(0) = V_0\) y no hay fuente: \[ v_C(t) = V_0 e^{-t/(RC)} \]

3. Circuito RL (Resistor-Inductor)

Un circuito RL serie satisface: \[ L \frac{di}{dt} + R i = v(t) \] donde \(i(t)\) es la corriente en el inductor.

3.1 Respuesta a escalón (\(v(t) = V_0\) constante)

La solución general es: \[ i(t) = \frac{V_0}{R} + C e^{-Rt/L} \] Con condición inicial \(i(0) = 0\): \[ i(t) = \frac{V_0}{R}(1 - e^{-Rt/L}) \]
Circuito RL con \(L=2\) H, \(R=4\ \Omega\), \(V_0=12\) V:
\(i(t) = 3(1 - e^{-2t})\) A.

3.2 Respuesta natural

Si el inductor tiene corriente inicial \(i(0) = I_0\) y no hay fuente: \[ i(t) = I_0 e^{-Rt/L} \]

4. Circuito RLC en serie

Un circuito RLC en serie satisface: \[ L \frac{d^2q}{dt^2} + R \frac{dq}{dt} + \frac{1}{C} q = v(t) \] o en términos de corriente: \[ L \frac{d^2i}{dt^2} + R \frac{di}{dt} + \frac{1}{C} i = \frac{dv}{dt} \]

4.1 Clasificación del amortiguamiento

Para el caso homogéneo \(Lq'' + Rq' + \frac{1}{C}q = 0\):
\(\alpha = \frac{R}{2L}\) (factor de amortiguamiento)
\(\omega_0 = \frac{1}{\sqrt{LC}}\) (frecuencia natural)
  • Sobreamortiguado: \(\alpha > \omega_0\) → raíces reales distintas
  • Críticamente amortiguado: \(\alpha = \omega_0\) → raíz real doble
  • Subamortiguado: \(\alpha < \omega_0\) → raíces complejas conjugadas
\(L=1\) H, \(R=6\ \Omega\), \(C=0.2\) F:
\(\alpha = 3\), \(\omega_0 = \sqrt{5} \approx 2.236\) → \(\alpha > \omega_0\) → sobreamortiguado.
Ecuación característica: \(r^2 + 6r + 5 = 0\) → \(r = -1, -5\)
\(q(t) = C_1 e^{-t} + C_2 e^{-5t}\).

5. Circuito RLC en paralelo

Un circuito RLC en paralelo satisface: \[ \frac{d^2v}{dt^2} + \frac{1}{RC}\frac{dv}{dt} + \frac{1}{LC}v = \frac{1}{C}\frac{di}{dt} \]

6. Análisis de transitorios

El comportamiento de un circuito tiene dos partes:
  • Régimen transitorio: parte que depende de las condiciones iniciales y decae con el tiempo.
  • Régimen permanente: comportamiento cuando \(t \to \infty\) (solución particular).

7. Resumen de constantes de tiempo

  • Circuito RC: \(\tau = RC\)
  • Circuito RL: \(\tau = L/R\)
  • Circuito RLC: \(\alpha = R/(2L)\), \(\omega_0 = 1/\sqrt{LC}\)
