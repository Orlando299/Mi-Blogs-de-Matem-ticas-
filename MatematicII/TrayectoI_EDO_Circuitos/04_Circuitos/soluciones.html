📝 Soluciones - Ejercicios

1. \(v_C(t) = 5(1 - e^{-10t})\) V, \(i(t) = 0.5 e^{-10t}\) A
2. \(v_C(t) = 10 - 8e^{-10t}\) V
3. \(RC = 1/20\) → \(R \cdot C = 0.05\)
4. \(v_C(t) = 12 e^{-t}\) V (con \(\tau = 1\) s)
5. \(t = RC \ln(4) \approx 0.25 \ln 4 \approx 0.346\) s
6. \(i(t) = 3(1 - e^{-2t})\) A
7. \(i(t) = 5 - 4e^{-4t}\) A
8. \(\tau = 0.5\) → \(L/R = 0.5\), \(V_0/R = 2\) → \(R=4\ \Omega\), \(L=2\) H
9. \(i(t) = 3 e^{-2t}\) A
10. \(t = \frac{L}{R}\ln 5 = 0.5 \ln 5 \approx 0.805\) s
11. \(\alpha = 2\), \(\omega_0 = \sqrt{5} \approx 2.236\) → sobreamortiguado: \(q(t) = C_1 e^{-0.764t} + C_2 e^{-3.236t}\)
12. \(\alpha = 1\), \(\omega_0 = 1\) → críticamente amortiguado: \(q(t) = (C_1 + C_2 t) e^{-t}\)
13. \(\alpha = 1\), \(\omega_0 = 2\) → subamortiguado: \(q(t) = e^{-t}(C_1 \cos \sqrt{3}t + C_2 \sin \sqrt{3}t)\)
14. \(q(t) = \frac{5}{4}e^{-t} - \frac{1}{4}e^{-5t}\)
15. \(q(t) = e^{-2t}(2\cos 2t + \frac{3}{2}\sin 2t)\)
16. \(q(t) = 2.5 - e^{-2t}(2.5\cos 2t + 2.5\sin 2t)\)
17. \(q_p(t) = A\cos 3t + B\sin 3t\) (se determinan A y B)
18. \(q(t) = e^{-2t}(C_1 \cos 2t + C_2 \sin 2t) + A\cos 2t + B\sin 2t\)
19. \(q(t) = e^{-t}(\cos t + \sin t)\)
20. \(q(t) = 10 - e^{-t}(10\cos t + 10\sin t)\)
