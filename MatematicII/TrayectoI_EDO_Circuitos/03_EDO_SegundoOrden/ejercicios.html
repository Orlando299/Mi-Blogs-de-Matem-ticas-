Ejercicios: EDO de Segundo Orden

MSc. Orlando Silva

Las soluciones están en soluciones.html (contraseña requerida).

1. EDO homogéneas (raíces reales distintas)

1. \(y'' - 3y' + 2y = 0\)
2. \(y'' + 5y' + 6y = 0\)
3. \(y'' - 4y' + 3y = 0\)
4. \(2y'' + 3y' - 2y = 0\)

2. EDO homogéneas (raíz real doble)

5. \(y'' + 4y' + 4y = 0\)
6. \(y'' - 6y' + 9y = 0\)
7. \(4y'' - 4y' + y = 0\)
8. \(y'' + 2y' + 1 = 0\)

3. EDO homogéneas (raíces complejas)

9. \(y'' + 4y = 0\)
10. \(y'' + 6y' + 13y = 0\)
11. \(y'' - 2y' + 5y = 0\)
12. \(4y'' + 4y' + 5y = 0\)

4. Problemas de Valor Inicial (PVI)

13. \(y'' - 3y' + 2y = 0\), \(y(0)=1\), \(y'(0)=0\)
14. \(y'' + 4y' + 4y = 0\), \(y(0)=2\), \(y'(0)=-1\)
15. \(y'' + 9y = 0\), \(y(0)=0\), \(y'(0)=3\)

5. EDO no homogéneas (coeficientes indeterminados)

16. \(y'' - 3y' + 2y = 4x^2\)
17. \(y'' + 4y = \sin(2x)\)
18. \(y'' - y' - 2y = e^{3x}\)
19. \(y'' + y = \cos x\)

6. Aplicaciones: Sistema masa-resorte

20. Un sistema masa-resorte tiene EDO \(x'' + 2x' + 10x = 0\). Encuentra la solución general. Clasifica el amortiguamiento.
21. Un sistema con \(x'' + 6x' + 9x = 0\). Encuentra la solución general y clasifica el amortiguamiento.
22. Un sistema con \(x'' + 4x = 0\). Encuentra la solución general y clasifica el amortiguamiento.

7. Aplicaciones: Circuitos RLC

23. En un circuito RLC con \(L=1\) H, \(R=4\ \Omega\), \(C=0.2\) F, encuentra \(q(t)\) para el caso homogéneo.
24. Para un circuito RLC con \(L=1\) H, \(R=2\ \Omega\), \(C=0.5\) F, \(V(t)=0\), condiciones iniciales \(q(0)=1\), \(i(0)=0\), encuentra \(q(t)\).

8. Variación de parámetros

25. Resuelve \(y'' - y = e^x\) usando variación de parámetros.
26. Resuelve \(y'' + y = \tan x\) usando variación de parámetros.
