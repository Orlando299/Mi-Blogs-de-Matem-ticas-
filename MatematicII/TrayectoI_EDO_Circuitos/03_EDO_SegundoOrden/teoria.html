Unidad 3: EDO de Segundo Orden

MSc. Orlando Silva
Matemática II · PNF Electricidad · Trayecto I

1. Definición y forma general

Una EDO lineal de segundo orden tiene la forma: \[ a_2(x)y'' + a_1(x)y' + a_0(x)y = g(x) \] donde \(a_2(x) \neq 0\). En este curso trabajaremos con coeficientes constantes: \[ a y'' + b y' + c y = g(x) \] donde \(a, b, c\) son constantes reales.

2. EDO homogénea (\(g(x)=0\))

La EDO homogénea de segundo orden con coeficientes constantes es: \[ a y'' + b y' + c y = 0 \]

Ecuación característica

Se propone solución \(y = e^{rx}\). Sustituyendo en la EDO: \[ a r^2 + b r + c = 0 \] Esta es la ecuación característica. Sus raíces determinan la forma de la solución general.

Caso 1: Raíces reales distintas (\(r_1 \neq r_2\))

\(y = C_1 e^{r_1 x} + C_2 e^{r_2 x}\)
\(y'' - 3y' + 2y = 0\) → \(r^2 - 3r + 2 = 0\) → \(r = 1, 2\) → \(y = C_1 e^{x} + C_2 e^{2x}\).

Caso 2: Raíces reales iguales (\(r_1 = r_2 = r\))

\(y = (C_1 + C_2 x) e^{r x}\)
\(y'' + 4y' + 4y = 0\) → \(r^2 + 4r + 4 = 0\) → \((r+2)^2 = 0\) → \(r = -2\) (doble) → \(y = (C_1 + C_2 x) e^{-2x}\).

Caso 3: Raíces complejas conjugadas (\(r = \alpha \pm \beta i\))

\(y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)\)
\(y'' + 4y = 0\) → \(r^2 + 4 = 0\) → \(r = \pm 2i\) → \(\alpha = 0, \beta = 2\) → \(y = C_1 \cos(2x) + C_2 \sin(2x)\).
\(y'' - 2y' + 5y = 0\) → \(r^2 - 2r + 5 = 0\) → \(r = 1 \pm 2i\) → \(y = e^{x}(C_1 \cos 2x + C_2 \sin 2x)\).

3. EDO no homogénea (\(g(x) \neq 0\))

La solución general es: \[ y = y_h + y_p \] donde \(y_h\) es la solución de la homogénea asociada y \(y_p\) es una solución particular de la no homogénea.

3.1 Método de coeficientes indeterminados

Se propone una solución particular \(y_p\) con la misma forma que \(g(x)\) y sus derivadas, con coeficientes a determinar.
\(y'' - 3y' + 2y = 4x^2\)
Propuesta: \(y_p = Ax^2 + Bx + C\).
Se calculan \(y_p'\) y \(y_p''\), se sustituyen en la EDO y se igualan coeficientes para hallar \(A, B, C\).

3.2 Método de variación de parámetros

Si \(y_1\) y \(y_2\) son soluciones de la homogénea, se propone: \[ y_p = u_1(x) y_1 + u_2(x) y_2 \] donde \[ u_1' = -\frac{y_2 g(x)}{W}, \quad u_2' = \frac{y_1 g(x)}{W} \] y \(W = y_1 y_2' - y_1' y_2\) es el Wronskiano.
\(y'' - y = e^x\). Homogénea: \(y'' - y = 0\) → \(y_1 = e^x, y_2 = e^{-x}\).
\(W = e^x(-e^{-x}) - e^x e^{-x} = -2\).
\(u_1' = -\frac{e^{-x} \cdot e^x}{-2} = \frac{1}{2}\) → \(u_1 = \frac{x}{2}\).
\(u_2' = \frac{e^x \cdot e^x}{-2} = -\frac{e^{2x}}{2}\) → \(u_2 = -\frac{e^{2x}}{4}\).
\(y_p = \frac{x}{2} e^x - \frac{e^{2x}}{4} e^{-x} = \frac{x}{2} e^x - \frac{e^x}{4} = \frac{e^x}{4}(2x - 1)\).

4. Aplicación a sistemas masa-resorte

Un sistema masa-resorte (con amortiguamiento) se modela con: \[ m x'' + \gamma x' + k x = F(t) \] donde \(m\) es la masa, \(\gamma\) el coeficiente de amortiguamiento, \(k\) la constante del resorte y \(F(t)\) la fuerza externa.
Caso homogéneo: \(x'' + 2x' + 10x = 0\).
Ecuación característica: \(r^2 + 2r + 10 = 0\) → \(r = -1 \pm 3i\).
Solución: \(x(t) = e^{-t}(C_1 \cos 3t + C_2 \sin 3t)\).
Sistema subamortiguado (oscilaciones amortiguadas).

5. Aplicación a circuitos RLC

Un circuito RLC en serie satisface: \[ L q'' + R q' + \frac{1}{C} q = V(t) \] o en términos de corriente: \[ L i'' + R i' + \frac{1}{C} i = V'(t) \]
Caso homogéneo con \(L=1\) H, \(R=2\ \Omega\), \(C=0.2\) F:
\(q'' + 2q' + 5q = 0\).
\(r^2 + 2r + 5 = 0\) → \(r = -1 \pm 2i\).
\(q(t) = e^{-t}(C_1 \cos 2t + C_2 \sin 2t)\).
Sistema subamortiguado.

6. Resumen de casos

  • Raíces reales distintas: \(y = C_1 e^{r_1 x} + C_2 e^{r_2 x}\)
  • Raíz real doble: \(y = (C_1 + C_2 x)e^{r x}\)
  • Raíces complejas: \(y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)\)
  • No homogénea: \(y = y_h + y_p\) (coeficientes indeterminados o variación de parámetros)
