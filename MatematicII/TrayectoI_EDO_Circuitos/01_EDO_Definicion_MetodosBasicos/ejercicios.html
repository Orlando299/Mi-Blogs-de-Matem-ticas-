Ejercicios: EDO - Definición, Clasificación y Métodos Básicos

MSc. Orlando Silva

Las soluciones están en soluciones.html (contraseña requerida).

1. Clasificación de EDO

1. Clasifica las siguientes ecuaciones por tipo, orden, grado y linealidad:
a) \(\frac{dy}{dx} + y = 0\)
b) \(\frac{d^2y}{dx^2} + 2\frac{dy}{dx} + y = e^x\)
c) \(\left(\frac{dy}{dx}\right)^2 + y = x\)
d) \(y\frac{dy}{dx} + y = 0\)
e) \(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0\)
2. Indica si las siguientes ecuaciones son homogéneas o no homogéneas:
a) \(y'' + 4y = 0\)
b) \(y'' - 3y' + 2y = \sin x\)
c) \(y' + y = e^x\)
d) \(y'' + 2y' + y = 0\)
3. Determina el orden y el grado de:
a) \(\frac{d^2y}{dx^2} + 3\frac{dy}{dx} + 2y = 0\)
b) \(\left(\frac{dy}{dx}\right)^3 + y = 0\)
c) \(\frac{d^3y}{dx^3} + \left(\frac{dy}{dx}\right)^2 = x\)

2. Variables separables

4. Resuelve: \(\frac{dy}{dx} = \frac{x}{y}\)
5. Resuelve: \(\frac{dy}{dx} = \frac{y+1}{x-2}\)
6. Resuelve: \(\frac{dy}{dx} = e^{x-y}\)
7. Resuelve: \(x\,dx + y\,dy = 0\)

3. Ecuaciones exactas

8. Verifica si es exacta y resuelve: \((2xy)\,dx + (x^2 - 1)\,dy = 0\)
9. Resuelve: \((3x^2y + y^2)\,dx + (x^3 + 2xy)\,dy = 0\)
10. Resuelve: \((e^x \sin y + y)\,dx + (e^x \cos y + x)\,dy = 0\)
11. Determina si \((y^2 + 2xy)\,dx + (x^2 + 2xy)\,dy = 0\) es exacta. Si lo es, resuélvela.

4. Problemas de Valor Inicial

12. Resuelve el PVI: \(\frac{dy}{dx} = \frac{y}{x}\), \(y(1) = 2\)
13. Resuelve el PVI: \((2x + y)\,dx + (x + 2y)\,dy = 0\), \(y(0) = 1\)

5. Aplicación a circuitos (introducción)

14. En un circuito RC, la carga \(q(t)\) satisface \(R\frac{dq}{dt} + \frac{1}{C}q = V_0\). Si \(R=2\Omega\), \(C=0.5F\), \(V_0=10V\), encuentra la solución general para \(q(t)\).
