1. Definición de Ecuación Diferencial

Una ecuación diferencial es una ecuación que contiene derivadas o diferenciales de una o más variables dependientes con respecto a una o más variables independientes.

Notación:

  • Prima: \(y', y'', y''', \dots, y^{(n)}\)
  • Leibniz: \(\frac{dy}{dx}, \frac{d^2y}{dx^2}, \dots, \frac{d^ny}{dx^n}\)
  • Operador: \(D y, D^2 y, \dots, D^n y\)

2. Clasificación de las Ecuaciones Diferenciales

2.1 Según el tipo

  • Ordinaria (EDO): una variable independiente.
  • Parcial (EDP): dos o más variables independientes.

2.2 Según el orden

El orden es la derivada más alta presente.
\(y' + y = x\) → orden 1; \(y'' + 3y' + 2y = 0\) → orden 2

2.3 Según el grado

El grado es el exponente de la derivada de mayor orden (si es polinómica).
\((y')^2 + 3y = 0\) → grado 2; \(y'' + (y')^3 = 0\) → grado 1

2.4 Según la linealidad

  • Lineal: \(y\) y sus derivadas aparecen linealmente.
  • No lineal: hay productos, potencias o funciones no lineales de \(y\).
Lineales: \(y' + 2y = e^x\), \(y'' - 3y' + 2y = 0\)
No lineales: \(y' + y^2 = x\), \(y y' + y = 0\)

2.5 Homogénea vs. No homogénea

\(a_n(x)y^{(n)} + \cdots + a_1(x)y' + a_0(x)y = g(x)\)
  • \(g(x) = 0\) → homogénea
  • \(g(x) \neq 0\) → no homogénea

3. Solución de una EDO

  • General: contiene constantes arbitrarias.
  • Particular: se obtiene asignando valores a las constantes.
  • Singular: no se obtiene de la general.

4. Problemas de Valor Inicial (PVI)

Una EDO con condiciones sobre la función y sus derivadas en un mismo punto.
\(y' + 2y = e^x\), \(y(0) = 1\)

5. Método de Variables Separables

Si la EDO se puede escribir como: \[ g(y)\,dy = f(x)\,dx \] entonces se integra directamente: \[ \int g(y)\,dy = \int f(x)\,dx + C \]
\(\frac{dy}{dx} = \frac{x}{y}\) → \(y\,dy = x\,dx\) → \(\frac{y^2}{2} = \frac{x^2}{2} + C\) → \(y^2 - x^2 = C\)

6. Método de Ecuaciones Exactas

Una EDO de la forma: \[ M(x,y)\,dx + N(x,y)\,dy = 0 \] es exacta si: \[ \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \]
Si es exacta, existe una función \(F(x,y)\) tal que: \[ \frac{\partial F}{\partial x} = M,\quad \frac{\partial F}{\partial y} = N \] y la solución es \(F(x,y) = C\).
\(2xy\,dx + (x^2 - 1)\,dy = 0\)
\(M = 2xy \Rightarrow \frac{\partial M}{\partial y} = 2x\)
\(N = x^2 - 1 \Rightarrow \frac{\partial N}{\partial x} = 2x\) → es exacta.
\(F = x^2 y - y\) → solución: \(x^2 y - y = C\) → \(y(x^2 - 1) = C\).

7. Existencia y Unicidad

Teorema de Picard-Lindelöf: Si \(f\) y \(\frac{\partial f}{\partial y}\) son continuas en un rectángulo que contiene a \((x_0, y_0)\), el PVI \(y' = f(x,y)\), \(y(x_0) = y_0\) tiene una única solución.
