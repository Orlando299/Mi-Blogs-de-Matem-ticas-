Ejercicios: Transformada de Laplace

MSc. Orlando Silva

Las soluciones están en soluciones.html (contraseña requerida).

1. Transformadas directas

1. \(\mathcal{L}\{3t^2 - 2e^{5t} + 4\sin(2t)\}\)
2. \(\mathcal{L}\{e^{-3t}\cos(2t)\}\)
3. \(\mathcal{L}\{t^2 e^{4t}\}\)
4. \(\mathcal{L}\{\sinh(3t)\}\)
5. \(\mathcal{L}\{\cosh(2t)\}\)

2. Teorema de traslación

6. \(\mathcal{L}\{e^{2t}\sin(3t)\}\)
7. \(\mathcal{L}\{e^{-t}\cos(4t)\}\)
8. \(\mathcal{L}\{t^3 e^{-2t}\}\)

3. Transformada inversa (fracciones parciales)

9. \(\mathcal{L}^{-1}\left\{\frac{1}{(s-1)(s-2)}\right\}\)
10. \(\mathcal{L}^{-1}\left\{\frac{s}{(s+1)(s+2)}\right\}\)
11. \(\mathcal{L}^{-1}\left\{\frac{1}{s^2+4s+3}\right\}\)
12. \(\mathcal{L}^{-1}\left\{\frac{s+1}{s^2+2s+5}\right\}\)

4. Problemas de Valor Inicial (PVI) con Laplace

13. \(y' + 2y = 4\), \(y(0) = 1\)
14. \(y' - y = e^{2x}\), \(y(0) = 0\)
15. \(y'' + 4y = 0\), \(y(0) = 1\), \(y'(0) = 0\)
16. \(y'' - 3y' + 2y = e^x\), \(y(0) = 0\), \(y'(0) = 0\)

5. Función escalón de Heaviside

17. Calcula \(\mathcal{L}\{u(t-2)\}\)
18. Calcula \(\mathcal{L}\{u(t-3)\sin(2t)\}\)
19. Encuentra \(\mathcal{L}\{f(t)\}\) donde \(f(t) = \begin{cases} 0 & t < 2 \\ 3 & t \geq 2 \end{cases}\)

6. Aplicaciones a circuitos

20. Usa Laplace para resolver la corriente en un circuito RL con \(L=2\) H, \(R=4\ \Omega\), \(V=12\) V constante, \(i(0)=0\).
21. Resuelve el circuito RC con \(R=10\ \Omega\), \(C=0.01\) F, \(V=5\) V constante, \(v_c(0)=0\) usando Laplace.

7. Teorema de convolución

22. Usa convolución para encontrar \(\mathcal{L}^{-1}\left\{\frac{1}{s^2(s-1)}\right\}\)
23. Usa convolución para encontrar \(\mathcal{L}^{-1}\left\{\frac{1}{s^2+4}\cdot\frac{1}{s+2}\right\}\)
