Unidad 5: Transformada de Laplace

MSc. Orlando Silva
Matemática II · PNF Electricidad · Trayecto II

1. Definición y existencia

La Transformada de Laplace de una función \(f(t)\) definida para \(t \geq 0\) es: \[ \mathcal{L}\{f(t)\} = F(s) = \int_0^\infty e^{-st} f(t)\,dt \] donde \(s\) es una variable compleja.
Condiciones de existencia: \(f(t)\) debe ser de orden exponencial (existen \(M > 0\) y \(\alpha\) tales que \(|f(t)| \leq M e^{\alpha t}\) para \(t\) grande) y debe ser continua por partes en todo intervalo finito.

2. Transformadas de funciones elementales

\[ \mathcal{L}\{1\} = \frac{1}{s}, \quad s > 0 \] \[ \mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}, \quad s > 0, \quad n = 0,1,2,\dots \] \[ \mathcal{L}\{e^{at}\} = \frac{1}{s-a}, \quad s > a \] \[ \mathcal{L}\{\sin(\omega t)\} = \frac{\omega}{s^2 + \omega^2}, \quad s > 0 \] \[ \mathcal{L}\{\cos(\omega t)\} = \frac{s}{s^2 + \omega^2}, \quad s > 0 \] \[ \mathcal{L}\{\sinh(at)\} = \frac{a}{s^2 - a^2}, \quad s > |a| \] \[ \mathcal{L}\{\cosh(at)\} = \frac{s}{s^2 - a^2}, \quad s > |a| \]

3. Propiedades fundamentales

3.1 Linealidad

\[ \mathcal{L}\{a f(t) + b g(t)\} = a\mathcal{L}\{f(t)\} + b\mathcal{L}\{g(t)\} \]

3.2 Teorema de traslación (primera)

\[ \mathcal{L}\{e^{at} f(t)\} = F(s-a) \]
\(\mathcal{L}\{e^{-3t}\cos(2t)\} = \frac{s+3}{(s+3)^2 + 4}\)

3.3 Teorema de traslación (segunda)

Si \(f(t)\) tiene transformada \(F(s)\), entonces: \[ \mathcal{L}\{f(t-a)u(t-a)\} = e^{-as}F(s) \] donde \(u(t-a)\) es la función escalón de Heaviside.

3.4 Transformada de la derivada

\[ \mathcal{L}\{f'(t)\} = sF(s) - f(0) \] \[ \mathcal{L}\{f''(t)\} = s^2F(s) - sf(0) - f'(0) \] Generalizando: \[ \mathcal{L}\{f^{(n)}(t)\} = s^nF(s) - s^{n-1}f(0) - s^{n-2}f'(0) - \cdots - f^{(n-1)}(0) \]

3.5 Transformada de la integral

\[ \mathcal{L}\left\{\int_0^t f(\tau)\,d\tau\right\} = \frac{F(s)}{s} \]

4. Transformada inversa

La transformada inversa de Laplace se denota por: \[ \mathcal{L}^{-1}\{F(s)\} = f(t) \]
Para encontrar la transformada inversa de funciones racionales, se usa:
  • Fracciones parciales: descomponer \(F(s)\) en términos más simples.
  • Uso de tablas: identificar términos con transformadas conocidas.
  • Teorema de convolución: \(\mathcal{L}^{-1}\{F(s)G(s)\} = f(t) * g(t) = \int_0^t f(\tau)g(t-\tau)d\tau\)
\(\mathcal{L}^{-1}\left\{\frac{1}{(s-1)(s-2)}\right\}\)
Descomponer: \(\frac{1}{(s-1)(s-2)} = \frac{1}{s-2} - \frac{1}{s-1}\)
Inversa: \(e^{2t} - e^{t}\)

5. Aplicación a PVI (Problemas de Valor Inicial)

Procedimiento:
  1. Aplicar la transformada de Laplace a ambos lados de la EDO.
  2. Usar las condiciones iniciales para obtener \(Y(s)\).
  3. Resolver algebraicamente para \(Y(s)\).
  4. Aplicar la transformada inversa para obtener \(y(t)\).
Resolver \(y' + 2y = e^{-t}\), \(y(0) = 1\).
Aplicando Laplace: \(sY(s) - 1 + 2Y(s) = \frac{1}{s+1}\)
\(Y(s) = \frac{1}{(s+2)(s+1)} + \frac{1}{s+2} = \frac{1}{s+1}\)
Inversa: \(y(t) = e^{-t}\)

6. Función escalón de Heaviside

La función escalón unitario (Heaviside) se define como: \[ u(t-a) = \begin{cases} 0 & t < a \\ 1 & t \geq a \end{cases} \]
\[ \mathcal{L}\{u(t-a)\} = \frac{e^{-as}}{s} \]
\(\mathcal{L}\{u(t-3)\} = \frac{e^{-3s}}{s}\)

7. Resumen de transformadas frecuentes

  • \(\mathcal{L}\{1\} = 1/s\)
  • \(\mathcal{L}\{t^n\} = n!/s^{n+1}\)
  • \(\mathcal{L}\{e^{at}\} = 1/(s-a)\)
  • \(\mathcal{L}\{\sin(\omega t)\} = \omega/(s^2+\omega^2)\)
  • \(\mathcal{L}\{\cos(\omega t)\} = s/(s^2+\omega^2)\)
  • \(\mathcal{L}\{u(t-a)\} = e^{-as}/s\)
  • \(\mathcal{L}\{e^{at}f(t)\} = F(s-a)\)
