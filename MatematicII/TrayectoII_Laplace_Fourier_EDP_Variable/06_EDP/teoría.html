1. Definición y clasificación

Una ecuación diferencial parcial (EDP) es una ecuación que contiene derivadas parciales de una función de dos o más variables independientes.

Clasificación según el tipo:

  • Elíptica: \(\nabla^2 u = 0\) (Laplace) o \(\nabla^2 u = f(x,y)\) (Poisson)
  • Parabólica: \(\frac{\partial u}{\partial t} = \alpha \nabla^2 u\) (Ecuación de calor)
  • Hiperbólica: \(\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u\) (Ecuación de onda)

2. Método de separación de variables

Procedimiento general:
  1. Suponer que la solución es producto de funciones de una sola variable: \(u(x,t) = X(x)T(t)\).
  2. Sustituir en la EDP y separar las variables, obteniendo dos EDOs.
  3. Resolver las EDOs con las condiciones de frontera.
  4. Construir la solución general como superposición de soluciones.

3. Ecuación de onda unidimensional

La ecuación de onda unidimensional describe el movimiento de una cuerda vibrante: \[ \frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad 0 < x < L, \quad t > 0 \] donde \(c^2 = \frac{T}{\rho}\) (tensión/densidad lineal).
Condiciones de frontera (cuerda fija en los extremos): \[ u(0,t) = 0, \quad u(L,t) = 0, \quad t > 0 \] Condiciones iniciales: \[ u(x,0) = f(x), \quad \frac{\partial u}{\partial t}(x,0) = g(x), \quad 0 < x < L \]
Solución por separación de variables: \[ u(x,t) = \sum_{n=1}^\infty \left(A_n \cos\left(\frac{n\pi c t}{L}\right) + B_n \sin\left(\frac{n\pi c t}{L}\right)\right) \sin\left(\frac{n\pi x}{L}\right) \] donde \(A_n = \frac{2}{L}\int_0^L f(x)\sin\left(\frac{n\pi x}{L}\right)dx\) y \(B_n = \frac{2}{n\pi c}\int_0^L g(x)\sin\left(\frac{n\pi x}{L}\right)dx\).

4. Ecuación de calor unidimensional

La ecuación de calor describe la conducción de calor en una barra: \[ \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}, \quad 0 < x < L, \quad t > 0 \] donde \(\alpha = \frac{k}{\rho c_p}\) es la difusividad térmica.
Condiciones de frontera (extremos a temperatura cero): \[ u(0,t) = 0, \quad u(L,t) = 0, \quad t > 0 \] Condición inicial: \[ u(x,0) = f(x), \quad 0 < x < L \]
Solución por separación de variables: \[ u(x,t) = \sum_{n=1}^\infty B_n e^{-\alpha \left(\frac{n\pi}{L}\right)^2 t} \sin\left(\frac{n\pi x}{L}\right) \] donde \(B_n = \frac{2}{L}\int_0^L f(x)\sin\left(\frac{n\pi x}{L}\right)dx\).

5. Ecuación de Laplace (potencial)

La ecuación de Laplace describe potenciales estacionarios (eléctricos, gravitatorios, fluidos): \[ \nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0 \] En coordenadas polares: \[ \frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial u}{\partial r}\right) + \frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2} = 0 \]
Solución para una placa rectangular: \(u(x,y) = \sum_{n=1}^\infty \left[A_n \sinh\left(\frac{n\pi y}{L}\right) + B_n \cosh\left(\frac{n\pi y}{L}\right)\right]\sin\left(\frac{n\pi x}{L}\right)\)

6. Resumen de EDP clásicas

  • Onda: \(\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}\)
  • Calor: \(\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}\)
  • Laplace: \(\nabla^2 u = 0\)
