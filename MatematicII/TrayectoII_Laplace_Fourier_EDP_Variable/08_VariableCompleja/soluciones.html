📝 Soluciones - Ejercicios

1. \(z = 5e^{i\theta}\), \(\theta = \arctan(4/3)\)
2. \((1+i)^2 = 2i\)
3. \(e^z = e^x(\cos y + i\sin y)\), \(u = e^x\cos y\), \(v = e^x\sin y\). \(u_x = e^x\cos y\), \(v_y = e^x\cos y\); \(u_y = -e^x\sin y\), \(-v_x = -e^x\sin y\). Es analítica.
4. \(f(z) = \bar{z} = x - iy\), \(u = x\), \(v = -y\). \(u_x = 1\), \(v_y = -1\) → no se cumple. No es analítica.
5. \(\sin z = \sin x\cosh y + i\cos x\sinh y\)
6. Por teorema de Cauchy, \(\oint z^2 dz = 0\)
7. \(2\pi i\)
8. \(e^z = \sum_{n=0}^\infty \frac{z^n}{n!}\)
9. \(\frac{1}{z(z-1)} = -\frac{1}{z} - \sum_{n=0}^\infty z^n\)
10. \(\text{Res}(f, i) = \frac{1}{2i}\)
11. 0 (suma de residuos = 0)
12. \(\pi\)

Pre‑parcial 2: 1. No es analítica (ver ejercicio 4); 2. \(e^z = \sum_{n=0}^\infty \frac{z^n}{n!}\); 3. 0; 4. \(\pi\)
