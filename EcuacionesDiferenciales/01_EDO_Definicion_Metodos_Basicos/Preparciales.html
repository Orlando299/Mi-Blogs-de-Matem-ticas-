Pre‑parcial 1

1. (12 puntos) Clasifica las siguientes ecuaciones por tipo (EDO/EDP), orden, grado y linealidad:
a) \(\frac{d^2y}{dx^2} + 2\frac{dy}{dx} + y = 0\)
b) \(\left(\frac{dy}{dx}\right)^2 + 3y = x\)
c) \(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial t^2} = 0\)
d) \(y'' + 4y = \cos x\)
2. (8 puntos) Determina si las siguientes funciones son soluciones de la EDO \(y'' - 3y' + 2y = 0\):
a) \(y = e^x\)
b) \(y = e^{2x}\)
c) \(y = e^{-x}\)
3. (10 puntos) Resuelve por variables separables: \(\frac{dy}{dx} = \frac{x}{y}\)
4. (10 puntos) Resuelve la ecuación exacta: \((2xy)\,dx + (x^2 - 1)\,dy = 0\)
5. (10 puntos) Resuelve el PVI: \(\frac{dy}{dx} = \frac{y+1}{x-2}\), \(y(0) = 1\)

Pre‑parcial 2

1. (12 puntos) Clasifica las siguientes ecuaciones:
a) \(\frac{d^3y}{dx^3} + \left(\frac{dy}{dx}\right)^2 = x\)
b) \(\frac{d^2y}{dx^2} + 3\frac{dy}{dx} + y = e^x\)
c) \(\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}\)
d) \((y'')^2 + y = 0\)
2. (8 puntos) Verifica que \(y = \sin x\) es solución de \(y'' + y = 0\).
3. (10 puntos) Resuelve por variables separables: \(\frac{dy}{dx} = e^{x-y}\)
4. (10 puntos) Resuelve la ecuación exacta: \((3x^2y + y^2)\,dx + (x^3 + 2xy)\,dy = 0\)
5. (10 puntos) Resuelve el PVI: \(x\,dx + y\,dy = 0\), \(y(1) = 2\)
