1. Ecuaciones Lineales de Primer Orden

Una EDO lineal de primer orden tiene la forma: \[ \frac{dy}{dx} + P(x)y = Q(x) \] donde \(P(x)\) y \(Q(x)\) son funciones continuas en un intervalo.

Método del factor integrante

El factor integrante es: \[ \mu(x) = e^{\int P(x)\,dx} \] Multiplicando la EDO por \(\mu(x)\), obtenemos: \[ \frac{d}{dx}\left(\mu(x) y\right) = \mu(x) Q(x) \] Integrando: \[ y = \frac{1}{\mu(x)} \left(\int \mu(x) Q(x)\,dx + C\right) \]
Ejemplo: Resolver \(y' + 2xy = x\).
\(P(x) = 2x\) → \(\mu = e^{\int 2x dx} = e^{x^2}\).
Multiplicando: \(e^{x^2}y' + 2xe^{x^2}y = x e^{x^2}\) → \(\frac{d}{dx}(e^{x^2}y) = x e^{x^2}\).
Integrando: \(e^{x^2}y = \int x e^{x^2}dx = \frac{1}{2}e^{x^2} + C\).
Solución: \(y = \frac{1}{2} + C e^{-x^2}\).

2. Ecuación de Bernoulli

La ecuación de Bernoulli tiene la forma: \[ \frac{dy}{dx} + P(x)y = Q(x)y^n \] donde \(n \neq 0,1\). Se resuelve mediante el cambio de variable: \[ z = y^{1-n} \] que transforma la ecuación en una EDO lineal de primer orden.
Procedimiento:
  1. Dividir entre \(y^n\): \(y^{-n}y' + P(x)y^{1-n} = Q(x)\)
  2. Hacer \(z = y^{1-n}\) → \(z' = (1-n)y^{-n}y'\)
  3. Sustituir: \(\frac{1}{1-n}z' + P(x)z = Q(x)\) → \(z' + (1-n)P(x)z = (1-n)Q(x)\)
  4. Resolver la EDO lineal en \(z\).
  5. Deshacer el cambio: \(y = z^{1/(1-n)}\).
Ejemplo: Resolver \(y' + y = xy^2\).
\(n=2\) → \(z = y^{-1}\) → \(y = z^{-1}\).
\(y' = -z^{-2}z'\). Sustituyendo: \(-z^{-2}z' + z^{-1} = x z^{-2}\).
Multiplicando por \(-z^2\): \(z' - z = -x\).
Resolviendo la lineal: \(z' - z = -x\). Factor integrante: \(\mu = e^{-x}\).
\(e^{-x}z' - e^{-x}z = -xe^{-x}\) → \(\frac{d}{dx}(e^{-x}z) = -xe^{-x}\).
Integrando: \(e^{-x}z = e^{-x}(x+1) + C\) → \(z = x+1 + C e^{x}\).
Solución: \(y = \frac{1}{x+1 + C e^{x}}\).

3. Aplicación a Circuitos RL

Un circuito RL (resistencia-inductor) satisface la EDO: \[ L\frac{di}{dt} + Ri = v(t) \] donde \(L\) es la inductancia, \(R\) la resistencia, \(i(t)\) la corriente y \(v(t)\) la tensión aplicada.
Ejemplo: Circuito RL con \(v(t) = V_0\) constante.
\(L\frac{di}{dt} + Ri = V_0\). Dividiendo entre \(L\): \(\frac{di}{dt} + \frac{R}{L}i = \frac{V_0}{L}\).
Es una EDO lineal de primer orden con \(P(t) = \frac{R}{L}\), \(Q(t) = \frac{V_0}{L}\).
Factor integrante: \(\mu = e^{\int \frac{R}{L}dt} = e^{Rt/L}\).
Solución: \(i(t) = \frac{V_0}{R} + C e^{-Rt/L}\).
Si \(i(0) = 0\): \(C = -\frac{V_0}{R}\) → \(i(t) = \frac{V_0}{R}(1 - e^{-Rt/L})\).

4. Aplicación a Circuitos RC

Un circuito RC (resistencia-condensador) satisface la EDO: \[ RC\frac{dv_c}{dt} + v_c = v(t) \] donde \(v_c(t)\) es la tensión en el condensador.
Ejemplo: Circuito RC con \(v(t) = V_0\) constante.
\(RC\frac{dv_c}{dt} + v_c = V_0\). Dividiendo entre \(RC\): \(\frac{dv_c}{dt} + \frac{1}{RC}v_c = \frac{V_0}{RC}\).
Factor integrante: \(\mu = e^{t/(RC)}\).
Solución: \(v_c(t) = V_0 + C e^{-t/(RC)}\).
Si \(v_c(0) = 0\): \(C = -V_0\) → \(v_c(t) = V_0(1 - e^{-t/(RC)})\).

5. Resumen de métodos

  • EDO lineal de primer orden: \(y' + P(x)y = Q(x)\) → factor integrante \(\mu = e^{\int P dx}\).
  • Bernoulli: \(y' + P(x)y = Q(x)y^n\) → cambio \(z = y^{1-n}\).
  • Circuito RL: \(L i' + R i = v(t)\) → lineal en \(i\).
  • Circuito RC: \(RC v_c' + v_c = v(t)\) → lineal en \(v_c\).
