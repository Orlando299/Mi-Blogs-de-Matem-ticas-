📝 Soluciones - Ejercicios

A. Límites por sustitución directa

1. \(\lim_{x\to 3}(2x^2 - 5x + 1) = 2(3)^2 - 5(3) + 1 = 18 - 15 + 1 = 4\)
2. \(\lim_{x\to -1}(x^3 + 2x^2 - x + 4) = (-1)^3 + 2(-1)^2 - (-1) + 4 = -1 + 2 + 1 + 4 = 6\)
3. \(\lim_{x\to 4}\sqrt{2x + 1} = \sqrt{2(4) + 1} = \sqrt{9} = 3\)
4. \(\lim_{x\to 2}\frac{3x^2 - x + 1}{x + 3} = \frac{3(2)^2 - 2 + 1}{2 + 3} = \frac{12 - 2 + 1}{5} = \frac{11}{5}\)
5. \(\lim_{x\to 0}\frac{\sin x + \cos x}{2 - x} = \frac{0 + 1}{2 - 0} = \frac{1}{2}\)

B. Indeterminación 0/0 (Factorización)

6. \(\lim_{x\to 2}\frac{x^2 - 4}{x - 2} = \lim_{x\to 2}\frac{(x-2)(x+2)}{x-2} = \lim_{x\to 2}(x+2) = 4\)
7. \(\lim_{x\to -3}\frac{x^2 - 9}{x + 3} = \lim_{x\to -3}\frac{(x-3)(x+3)}{x+3} = \lim_{x\to -3}(x-3) = -6\)
8. \(\lim_{x\to 1}\frac{x^3 - 1}{x - 1} = \lim_{x\to 1}\frac{(x-1)(x^2+x+1)}{x-1} = 1^2+1+1 = 3\)
9. \(\lim_{x\to 2}\frac{x^2 - 5x + 6}{x^2 - 4} = \lim_{x\to 2}\frac{(x-2)(x-3)}{(x-2)(x+2)} = \frac{2-3}{2+2} = -\frac{1}{4}\)
10. \(\lim_{x\to -1}\frac{x^4 - 1}{x^3 + 1} = \lim_{x\to -1}\frac{(x^2-1)(x^2+1)}{(x+1)(x^2-x+1)} = \lim_{x\to -1}\frac{(x-1)(x+1)(x^2+1)}{(x+1)(x^2-x+1)} = \frac{(-2)(2)}{1+1+1} = -\frac{4}{3}\)

B. Indeterminación 0/0 (Racionalización)

11. \(\lim_{x\to 0}\frac{\sqrt{x+4}-2}{x} \cdot \frac{\sqrt{x+4}+2}{\sqrt{x+4}+2} = \lim_{x\to 0}\frac{x+4-4}{x(\sqrt{x+4}+2)} = \frac{1}{\sqrt{4}+2} = \frac{1}{4}\)
12. \(\lim_{x\to 9}\frac{\sqrt{x}-3}{x-9} \cdot \frac{\sqrt{x}+3}{\sqrt{x}+3} = \lim_{x\to 9}\frac{x-9}{(x-9)(\sqrt{x}+3)} = \frac{1}{\sqrt{9}+3} = \frac{1}{6}\)
13. \(\lim_{x\to 0}\frac{\sqrt{1+x}-\sqrt{1-x}}{x} \cdot \frac{\sqrt{1+x}+\sqrt{1-x}}{\sqrt{1+x}+\sqrt{1-x}} = \lim_{x\to 0}\frac{1+x-(1-x)}{x(\sqrt{1+x}+\sqrt{1-x})} = \lim_{x\to 0}\frac{2x}{x(...)} = \frac{2}{1+1} = 1\)
14. \(\lim_{x\to 5}\frac{\sqrt{x+4}-3}{x-5} \cdot \frac{\sqrt{x+4}+3}{\sqrt{x+4}+3} = \lim_{x\to 5}\frac{x+4-9}{(x-5)(\sqrt{x+4}+3)} = \frac{1}{\sqrt{9}+3} = \frac{1}{6}\)
15. \(\lim_{x\to 1}\frac{\sqrt[3]{x}-1}{x-1}\). Cambio \(u=\sqrt[3]{x} \implies x=u^3\). \(\lim_{u\to 1}\frac{u-1}{u^3-1} = \lim_{u\to 1}\frac{u-1}{(u-1)(u^2+u+1)} = \frac{1}{3}\)

C. Indeterminación ∞/∞

16. \(\lim_{x\to\infty}\frac{3x+1}{2x-5} = \lim_{x\to\infty}\frac{3 + 1/x}{2 - 5/x} = \frac{3}{2}\)
17. \(\lim_{x\to\infty}\frac{5x^2-2x+1}{3x^2+x} = \frac{5}{3}\) (Mismo grado, coeficientes principales)
18. \(\lim_{x\to\infty}\frac{4x^3-x}{2x^2+7} = \infty\) (Grado numerador > denominador)
19. \(\lim_{x\to\infty}\frac{2x^2+x-1}{x^3+5} = 0\) (Grado numerador < denominador)
20. \(\lim_{x\to\infty}\frac{\sqrt{4x^2+3x}}{x+2} = \lim_{x\to\infty}\frac{x\sqrt{4+3/x}}{x(1+2/x)} = \frac{\sqrt{4}}{1} = 2\)

D. Indeterminación ∞ - ∞

21. \(\lim_{x\to\infty}(\sqrt{x^2+x}-x) \cdot \frac{\sqrt{x^2+x}+x}{\sqrt{x^2+x}+x} = \lim_{x\to\infty}\frac{x}{\sqrt{x^2+x}+x} = \frac{1}{2}\)
22. \(\lim_{x\to\infty}(\sqrt{x^2+5x}-x) = \frac{5}{2}\) (Mismo procedimiento que el 21)
23. \(\lim_{x\to\infty}(\sqrt{x^2+3x}-\sqrt{x^2-x}) = \lim_{x\to\infty}\frac{x^2+3x - (x^2-x)}{\sqrt{...}+\sqrt{...}} = \frac{4x}{2x} = 2\)
24. \(\lim_{x\to 1}\left(\frac{1}{x-1} - \frac{2}{x^2-1}\right) = \lim_{x\to 1}\frac{x+1-2}{x^2-1} = \lim_{x\to 1}\frac{x-1}{(x-1)(x+1)} = \frac{1}{2}\)
25. \(\lim_{x\to 2}\left(\frac{3}{x-2} - \frac{6}{x^2-4}\right) = \lim_{x\to 2}\frac{3(x+2)-6}{x^2-4} = \lim_{x\to 2}\frac{3x}{x^2-4} = \infty\)

E. Indeterminación 0 · ∞

26. \(\lim_{x\to 0^+} x\ln x = \lim_{x\to 0^+}\frac{\ln x}{1/x}\). Por L'Hôpital (o crecimiento): \(\lim_{x\to 0^+}\frac{1/x}{-1/x^2} = \lim_{x\to 0^+}(-x) = 0\)
27. \(\lim_{x\to\infty} x \sin(1/x)\). Cambio \(u=1/x\): \(\lim_{u\to 0}\frac{\sin u}{u} = 1\)
28. \(\lim_{x\to\infty} x(e^{1/x}-1)\). Cambio \(u=1/x\): \(\lim_{u\to 0}\frac{e^u-1}{u} = 1\) (límite notable)
29. \(\lim_{x\to 0^+} x^2\ln x = \lim_{x\to 0^+}\frac{\ln x}{1/x^2} = \lim_{x\to 0^+}\frac{1/x}{-2/x^3} = \lim_{x\to 0^+}\frac{-x^2}{2} = 0\)
30. \(\lim_{x\to\infty} x(\sqrt{1+1/x}-1)\). Multiplicando por el conjugado: \(x \cdot \frac{1/x}{\sqrt{1+1/x}+1} = \frac{1}{\sqrt{1}+1} = \frac{1}{2}\)

F. Indeterminaciones 1^∞, 0^0, ∞^0

31. \(\lim_{x\to\infty}(1+1/x)^x = e\)
32. \(\lim_{x\to\infty}(1+3/x)^x = e^3\)
33. \(\lim_{x\to 0^+} x^x\). Sea \(y=x^x \implies \ln y = x\ln x\). Como \(\lim x\ln x = 0\), \(\ln y \to 0 \implies y \to e^0 = 1\)
34. \(\lim_{x\to 0^+}(1+x)^{1/x} = e\) (límite notable)
35. \(\lim_{x\to\infty} x^{1/x}\). Sea \(y=x^{1/x} \implies \ln y = \frac{\ln x}{x}\). Aplicando L'Hôpital: \(\lim \frac{1/x}{1} = 0\). Por lo tanto \(y \to e^0 = 1\)

G. Continuidad

36. \(f(x) = \frac{x^2-9}{x-3}\) en \(x=3\). \(\lim_{x\to 3} f(x) = 6\), pero \(f(3)\) no está definida. Discontinuidad evitable.
37. \(f(x)\) a trozos en \(x=1\). Límite izq = \(2(1)+1=3\), Límite der = \((1)^2+3=4\). Como \(3 \neq 4\), discontinuidad de salto.
38. \(f(x) = \frac{\sin x}{x}\) con \(f(0)=0\). \(\lim_{x\to 0}\frac{\sin x}{x} = 1 \neq f(0)\). Discontinuidad evitable.
39. G.2.1: a) \(f(2)=1\); b) Límite = 4; c) No es continua, discont. evitable; d) Se redefine \(f(2)=4\).
40. G.2.2: a) Límite izq = 4, Límite der = 3; b) No existe el límite; c) Discontinuidad de salto.
41. G.2.3: a) Límite izq = \(-\infty\), Límite der = \(+\infty\); b) No existe; c) Discontinuidad infinita; d) Asíntota \(x=3\).
42. G.2.4: a) \(f(0)=5\); b) Límite izq = 1, Límite der = 1 (coinciden); c) Límite = 1; d) No es continua, discont. evitable; e) \(f(0)\) debería ser \(1\).

📝 Soluciones - Pre-parciales

Pre-parcial 1 (Tipo A)

1. Graficación \(f(x) = |x-2|\): Es una "V" con vértice en \((2,0)\). Dominio: \(\mathbb{R}\). Rango: \([0, +\infty)\).
2. Laterales: a) \(x\to 1\): Límite izq = \(3(1)-1 = 2\), Límite der = \(1^2+1 = 2\). Como coinciden, el límite existe y es 2. b) \(x\to 3\): \(3 \geq 1\), aplica la 2da rama. \(\lim_{x\to 3}(x^2+1) = 10\).
3. Factorización: a) \(\lim_{x\to 2}\frac{(x-2)(x+2)}{(x-2)(x+1)} = \frac{4}{3}\). b) \(\lim_{x\to 1}\frac{(x-1)(x^2+x+1)}{(x-1)(x+1)} = \frac{3}{2}\).
4. Racionalización: a) \(\lim_{x\to 0}\frac{x+4-4}{x(\sqrt{x+4}+2)} = \frac{1}{4}\). b) Multiplicando por conjugado: \(\lim_{x\to 9}\frac{(x-9)(\sqrt{x}+3)}{x-9} = 6\).
5. Infinito y Continuidad: a) \(\lim_{x\to\infty}\frac{5x^3+...}{2x^3+...} = \frac{5}{2}\). b) \(\lim_{x\to 3}\frac{x^2-9}{x-3} = 6\). Para que sea continua, \(k=6\).

Pre-parcial 2 (Tipo B)

1. Graficación \(f(x) = \sqrt{x+2}\): Curva que empieza en \((-2,0)\) y va hacia la derecha. Dominio: \([-2, +\infty)\). Rango: \([0, +\infty)\).
2. Laterales: a) \(x\to 2\): Límite izq = \(2(2)+1 = 5\), Límite der = \(2^2-3 = 1\). Como \(5 \neq 1\), el límite no existe. b) \(x\to 0\): \(0 < 2\), aplica la 1ra rama. \(\lim_{x\to 0}(2x+1) = 1\).
3. Factorización: a) \(\lim_{x\to -3}\frac{(x-3)(x+3)}{(x+3)(x-2)} = \frac{-6}{-5} = \frac{6}{5}\). b) \(\lim_{x\to 2}\frac{(x-2)(x^2+2x+4)}{(x-2)(x+2)} = \frac{12}{4} = 3\).
4. Racionalización: a) \(\lim_{x\to 0}\frac{x+9-9}{x(\sqrt{x+9}+3)} = \frac{1}{6}\). b) Multiplicando por conjugado: \(\lim_{x\to 4}\frac{(x-4)(\sqrt{x}+2)}{x-4} = 4\).
5. Infinito y Continuidad: a) \(\lim_{x\to\infty}\frac{4x^2+...}{2x^2+...} = \frac{4}{2} = 2\). b) \(\lim_{x\to 1}\frac{x^2-1}{x-1} = 2\). Para que sea continua, \(c=2\).
