Instrucciones. Deriva cada una de las siguientes funciones. Muestra claramente el procedimiento aplicando las reglas correspondientes (potencia, producto, cociente, cadena, etc.).

A. Reglas Básicas de Derivación

A.1 Suma y Resta

  1. 🟢 \(f(x) = 4x^3 - 2x^2 + 5x - 7\)
  2. 🟢 \(f(x) = \frac{1}{2}x^4 + \frac{2}{3}x^3 - x + 10\)
  3. 🟡 \(f(x) = 3\sqrt{x} + \frac{4}{x} - x^2\)
  4. 🟡 \(f(x) = \frac{x^4 - 3x^2 + 1}{x}\)
  5. 🔴 \(f(x) = (x+1)^2 + (x-1)^2\)
  6. 🔴 \(f(x) = \frac{3x^2 - 2x + 1}{\sqrt{x}}\)

A.2 Regla del Producto

  1. 🟢 \(f(x) = (x^2)(3x + 1)\)
  2. 🟢 \(f(x) = (2x - 1)(x^3 + 2)\)
  3. 🟡 \(f(x) = (x^2 + 1)(x^3 - x)\)
  4. 🟡 \(f(x) = (x^2 + 3x)(x^2 - 2x)\)
  5. 🔴 \(f(x) = (x^3 - 4x)(\sqrt{x} + 1)\)
  6. 🔴 \(f(x) = (x^2 + 1)(x^3 + 1)(x^4 + 1)\)

A.3 Regla del Cociente

  1. 🟢 \(f(x) = \frac{x+1}{x-1}\)
  2. 🟢 \(f(x) = \frac{2x}{x^2+1}\)
  3. 🟡 \(f(x) = \frac{x^2+1}{x^2-1}\)
  4. 🟡 \(f(x) = \frac{3x^2 - 1}{x+2}\)
  5. 🔴 \(f(x) = \frac{x^3 - 1}{x^2 + 1}\)
  6. 🔴 \(f(x) = \frac{x}{\sqrt{x} + 1}\)

A.4 Potencias, Raíces y 1/x

  1. 🟢 \(f(x) = x^{10}\)
  2. 🟢 \(f(x) = x^{-3}\)
  3. 🟢 \(f(x) = \sqrt{x}\)
  4. 🟢 \(f(x) = \sqrt[3]{x}\)
  5. 🟡 \(f(x) = \frac{1}{x^2}\)
  6. 🟡 \(f(x) = \frac{1}{\sqrt{x}}\)
  7. 🟡 \(f(x) = x^{3/2}\)
  8. 🟡 \(f(x) = x^{-2/3}\)
  9. 🔴 \(f(x) = \sqrt{x^3}\)
  10. 🔴 \(f(x) = \frac{1}{x\sqrt{x}}\)
  11. 🔴 \(f(x) = \sqrt[4]{x^3}\)
  12. 🔴 \(f(x) = \frac{5}{x^4}\)

B. Funciones Elementales

B.1 Exponenciales y Logarítmicas

  1. 🟢 \(f(x) = e^x + x^2\)
  2. 🟢 \(f(x) = \ln(x) + 3x\)
  3. 🟡 \(f(x) = x^2 e^x\)
  4. 🟡 \(f(x) = \frac{\ln x}{x}\)
  5. 🔴 \(f(x) = x \ln(x) - x\)
  6. 🔴 \(f(x) = a^x \ln(x)\)

B.2 Trigonométricas

  1. 🟢 \(f(x) = \sin x + \cos x\)
  2. 🟢 \(f(x) = \tan x - x\)
  3. 🟡 \(f(x) = x \sin x\)
  4. 🟡 \(f(x) = \frac{\cos x}{x}\)
  5. 🔴 \(f(x) = \sec x + \csc x\)
  6. 🔴 \(f(x) = \cot x \cdot \sin x\)

C. Regla de la Cadena

C.1 Cadena Básica

  1. 🟢 \(f(x) = (3x + 1)^5\)
  2. 🟢 \(f(x) = \sqrt{4x^2 + 1}\)
  3. 🟡 \(f(x) = e^{3x^2}\)
  4. 🟡 \(f(x) = \ln(5x + 2)\)
  5. 🔴 \(f(x) = \sin(x^3)\)
  6. 🔴 \(f(x) = \cos(e^x)\)

C.2 Cadena Combinada (Producto y Cociente)

  1. 🟡 \(f(x) = x^2 (x+1)^4\)
  2. 🟡 \(f(x) = e^x \sqrt{x+1}\)
  3. 🟡 \(f(x) = \frac{(x+1)^2}{x}\)
  4. 🔴 \(f(x) = (x^2+1)^3 \ln x\)
  5. 🔴 \(f(x) = \frac{e^x}{(x+1)^2}\)
  6. 🔴 \(f(x) = \sin x (x^2+1)^5\)

C.3 Cadena Anidada

  1. 🟡 \(f(x) = \sqrt{(x^2+1)^3}\)
  2. 🟡 \(f(x) = e^{\sin x}\)
  3. 🔴 \(f(x) = \ln(\cos(x^2))\)
  4. 🔴 \(f(x) = \sin^2(3x)\)
  5. 🔴 \(f(x) = \sqrt{\ln(x)}\)
  6. 🔴 \(f(x) = \cos^2(\sqrt{x})\)

D. Derivación Implícita

  1. 🟢 \(x^2 + y^2 = 25\)
  2. 🟢 \(xy = 1\)
  3. 🟢 \(x^2 + y^2 = 4xy\)
  4. 🟡 \(x^3 + y^3 = 8\)
  5. 🟡 \(x^2 y + y^2 x = 3\)
  6. 🟡 \(y^2 = x^3\)
  7. 🔴 \(\sin y = x^2 y\)
  8. 🔴 \(e^y = x + y\)
  9. 🔴 \(\ln(x+y) = y\)
  10. 🔴 \(x \cos y = y \sin x\)

E. Orden Superior, Rectas Tangentes y Aplicaciones

  1. 🟢 Dada \( f(x) = x^4 - 2x^3 + x \), hallar su segunda derivada \( f''(x) \).
  2. 🟢 Dada \( f(x) = e^{2x} \), hallar el valor de \( f''(0) \).
  3. 🟡 Dada \( f(x) = \sin x \), hallar la cuarta derivada \( f^{(4)}(x) \).
  4. 🟡 Encontrar la ecuación de la recta tangente a \( y = x^2 - 3x + 1 \) en el punto \( x=2 \).
  5. 🟡 Encontrar la ecuación de la recta normal a \( y = x^2 \) en el punto \( x=1 \).
  6. 🟡 Un móvil se desplaza según \( s(t) = 2t^3 - 3t^2 + 4t \). Hallar su velocidad y aceleración en \( t=1 \).
  7. 🔴 Encontrar los puntos donde la recta tangente a \( f(x) = x^3 - 3x^2 + 1 \) es horizontal.
  8. 🔴 Encontrar el punto donde la tangente a \( y = \frac{1}{x} \) es paralela a la recta \( x + 4y = 0 \).
  9. 🔴 Un globo esférico se infla y su radio crece a razón de \( 2 \, \text{cm/s} \). ¿A qué razón crece su volumen cuando el radio es \( 5 \, \text{cm} \)? (Fórmula: \( V = \frac{4}{3}\pi r^3 \)).
  10. 🔴 Determinar los valores de \( a \) y \( b \) para que la función \( f(x) = ax^3 + bx^2 \) tenga un punto de tangencia horizontal en \( (1, 4) \).
