A.1 Suma y Resta

5. \(f(x) = 2x^2 + 2 \implies f'(x) = 4x\)
6. \(f(x) = 3x^{3/2} - 2x^{1/2} + x^{-1/2} \implies f'(x) = \frac{9}{2}x^{1/2} - x^{-1/2} - \frac{1}{2}x^{-3/2}\)

A.2 Regla del Producto

7. \(f'(x) = (2x)(3x+1) + (x^2)(3) = 6x^2 + 2x + 3x^2 = 9x^2 + 2x\)
8. \(f'(x) = (2)(x^3+2) + (2x-1)(3x^2) = 2x^3 + 4 + 6x^3 - 3x^2 = 8x^3 - 3x^2 + 4\)
9. \(f'(x) = (2x)(x^3-x) + (x^2+1)(3x^2-1) = 2x^4 - 2x^2 + 3x^4 + 2x^2 - 1 = 5x^4 - 1\)
10. \(f'(x) = (2x+3)(x^2-2x) + (x^2+3x)(2x-2) = 2x^3 - 4x^2 + 3x^2 - 6x + 2x^3 - 2x^2 + 6x^2 - 6x = 4x^3 + 3x^2 - 12x\)
11. \(f'(x) = (3x^2-4)(\sqrt{x}+1) + (x^3-4x)\left(\frac{1}{2\sqrt{x}}\right) = 3x^{5/2} + 3x^2 - 4\sqrt{x} - 4 + \frac{1}{2}x^{5/2} - 2\sqrt{x} = \frac{7}{2}x^{5/2} + 3x^2 - 6\sqrt{x} - 4\)
12. Usando producto doble o expandiendo: \(f(x) = (x^5 + x^3 + x^2 + 1)(x^4+1) = x^9 + x^7 + x^6 + x^4 + x^5 + x^3 + x^2 + 1\). \(f'(x) = 9x^8 + 7x^6 + 6x^5 + 5x^4 + 4x^3 + 3x^2 + 2x\)

A.3 Regla del Cociente

13. \(f'(x) = \frac{(1)(x-1) - (x+1)(1)}{(x-1)^2} = \frac{-2}{(x-1)^2}\)
14. \(f'(x) = \frac{(2)(x^2+1) - (2x)(2x)}{(x^2+1)^2} = \frac{2x^2+2-4x^2}{(x^2+1)^2} = \frac{2-2x^2}{(x^2+1)^2}\)
15. \(f'(x) = \frac{(2x)(x^2-1) - (x^2+1)(2x)}{(x^2-1)^2} = \frac{2x^3-2x-2x^3-2x}{(x^2-1)^2} = \frac{-4x}{(x^2-1)^2}\)
16. \(f'(x) = \frac{(6x)(x+2) - (3x^2-1)(1)}{(x+2)^2} = \frac{6x^2+12x-3x^2+1}{(x+2)^2} = \frac{3x^2+12x+1}{(x+2)^2}\)
17. \(f'(x) = \frac{(3x^2)(x^2+1) - (x^3-1)(2x)}{(x^2+1)^2} = \frac{3x^4+3x^2-2x^4+2x}{(x^2+1)^2} = \frac{x^4+3x^2+2x}{(x^2+1)^2}\)
18. \(f'(x) = \frac{(1)(\sqrt{x}+1) - (x)(\frac{1}{2\sqrt{x}})}{(\sqrt{x}+1)^2} = \frac{\sqrt{x}+1 - \frac{1}{2}\sqrt{x}}{(\sqrt{x}+1)^2} = \frac{\frac{1}{2}\sqrt{x}+1}{(\sqrt{x}+1)^2}\)

C.2 Cadena Combinada

49. \(f'(x) = 2x(x+1)^4 + x^2 \cdot 4(x+1)^3 \cdot 1 = 2x(x+1)^3 [ (x+1) + 2x ] = 2x(x+1)^3(3x+1)\)

51. \(f'(x) = \frac{2(x+1)(1)(x) - (x+1)^2(1)}{x^2} = \frac{(x+1)[2x - (x+1)]}{x^2} = \frac{(x+1)(x-1)}{x^2}\)
52. \(f'(x) = 3(x^2+1)^2(2x)\ln x + (x^2+1)^3 \frac{1}{x} = (x^2+1)^2 \left[ 6x\ln x + \frac{x^2+1}{x} \right]\)
53. \(f'(x) = \frac{e^x(x+1)^2 - e^x(2)(x+1)}{(x+1)^4} = \frac{e^x(x+1) - 2e^x}{(x+1)^3} = \frac{e^x(x-1)}{(x+1)^3}\)
54. \(f'(x) = \cos x(x^2+1)^5 + \sin x \cdot 5(x^2+1)^4(2x) = (x^2+1)^4 [ \cos x(x^2+1) + 10x\sin x ]\)

D. Derivación Implícita

61. \(2x + 2y y' = 0 \implies y' = -\frac{x}{y}\)
62. \(y + x y' = 0 \implies y' = -\frac{y}{x}\)
63. \(2x + 2y y' = 4y + 4x y' \implies y'(2y - 4x) = 4y - 2x \implies y' = \frac{2y - x}{y - 2x}\)
64. \(3x^2 + 3y^2 y' = 0 \implies y' = -\frac{x^2}{y^2}\)
65. \(2xy + x^2 y' + 2y y' x + y^2 = 0 \implies y'(x^2+2xy) = -2xy-y^2 \implies y' = -\frac{2xy+y^2}{x^2+2xy}\)
66. \(2y y' = 3x^2 \implies y' = \frac{3x^2}{2y}\)
67. \(\cos y \cdot y' = 2xy + x^2 y' \implies y'(\cos y - x^2) = 2xy \implies y' = \frac{2xy}{\cos y - x^2}\)
68. \(e^y y' = 1 + y' \implies y'(e^y - 1) = 1 \implies y' = \frac{1}{e^y - 1}\)
69. \(\frac{1+y'}{x+y} = y' \implies 1+y' = y'(x+y) \implies 1 = y'(x+y-1) \implies y' = \frac{1}{x+y-1}\)
70. \(\cos y - xy'\sin y = y'\sin x + y\cos x \implies y'(-x\sin y - \sin x) = y\cos x - \cos y \implies y' = \frac{y\cos x - \cos y}{-x\sin y - \sin x}\)

E. Orden Superior y Aplicaciones

71. \(f'(x) = 4x^3 - 6x^2 + 1 \implies f''(x) = 12x^2 - 12x\)
72. \(f'(x) = 2e^{2x} \implies f''(x) = 4e^{2x} \implies f''(0) = 4\)
73. \(f'(x)=\cos x, f''(x)=-\sin x, f'''(x)=-\cos x, f^{(4)}(x)=\sin x\)
74. En \(x=2\), \(y= -1\). \(f'(x) = 2x-3 \implies m = f'(2) = 1\). Recta: \(y + 1 = 1(x - 2) \implies y = x - 3\)
75. En \(x=1\), \(y=1\). \(f'(x) = 2x \implies m = 2\). Pendiente normal: \(m_n = -1/2\). Recta: \(y - 1 = -1/2(x - 1) \implies y = -x/2 + 3/2\)
76. \(v(t) = 6t^2 - 6t + 4\), \(a(t) = 12t - 6\). En \(t=1\): \(v(1) = 4\), \(a(1) = 6\)
77. \(f'(x) = 3x^2 - 6x = 0 \implies 3x(x-2) = 0 \implies x=0, x=2\). Puntos: \((0,1)\) y \((2, -3)\)
78. Pendiente de recta dada: \(m = -1/4\). Igualamos \(f'(x) = -1/x^2 = -1/4 \implies x^2 = 4 \implies x = \pm 2\). Puntos: \((2, 1/2)\) y \((-2, -1/2)\)
79. \(V = \frac{4}{3}\pi r^3 \implies \frac{dV}{dt} = 4\pi r^2 \frac{dr}{dt}\). Con \(r=5\) y \(dr/dt=2\), \(\frac{dV}{dt} = 4\pi(25)(2) = 200\pi \, \text{cm}^3\text{/s}\)
80. \(f(1) = a+b = 4\). \(f'(x) = 3ax^2 + 2bx \implies f'(1) = 3a+2b = 0\). Resolviendo: \(a = -8, b = 12\)

📝 Soluciones - Pre-parciales

Pre-parcial 1 (Tipo A)

1. Reglas Básicas:
a) \(f'(x) = 20x^3 - 6x + 2\)
b) \(f'(x) = 4x(3x-4) + 3(2x^2+1) = 12x^2 - 16x + 6x^2 + 3 = 18x^2 - 16x + 3\)
c) \(f'(x) = \frac{2x(x-1) - (x^2+2)(1)}{(x-1)^2} = \frac{x^2-2x-2}{(x-1)^2}\)
2. Elementales:
a) \(f'(x) = 2xe^x + x^2e^x = e^x(x^2+2x)\)
b) \(f'(x) = \frac{\frac{1}{x}(x) - \ln x}{x^2} = \frac{1-\ln x}{x^2}\)
3. Cadena:
a) \(f'(x) = 4(3x^2+2)^3(6x) = 24x(3x^2+2)^3\)
b) \(f'(x) = \cos(4x) \cdot 4 = 4\cos(4x)\)
c) \(f'(x) = e^{\sqrt{x}} \cdot \frac{1}{2\sqrt{x}} = \frac{e^{\sqrt{x}}}{2\sqrt{x}}\)
4. Implícita: \(2x + 6yy' = 0 \implies y' = -\frac{x}{3y}\)
5. Tangente: En \(x=2\), \(y=5\). \(f'(x)=3x^2-2 \implies m = 10\). Recta: \(y-5 = 10(x-2) \implies y = 10x - 15\)

Pre-parcial 2 (Tipo B)

1. Reglas Básicas:
a) \(f'(x) = 12x^2 - 4x + 5\)
b) \(f'(x) = 3x^2(2x+1) + 2(x^3-2) = 6x^3 + 3x^2 + 2x^3 - 4 = 8x^3 + 3x^2 - 4\)
c) \(f'(x) = \frac{4x(x+3) - (2x^2-1)(1)}{(x+3)^2} = \frac{2x^2+12x+1}{(x+3)^2}\)
2. Elementales:
a) \(f'(x) = 3x^2\ln x + x^3\frac{1}{x} = 3x^2\ln x + x^2 = x^2(3\ln x + 1)\)
b) \(f'(x) = \frac{e^x(x^2) - e^x(2x)}{x^4} = \frac{e^x(x-2)}{x^3}\)
3. Cadena:
a) \(f'(x) = 3(5x^3-1)^2(15x^2) = 45x^2(5x^3-1)^2\)
b) \(f'(x) = -\sin(3x) \cdot 3 = -3\sin(3x)\)
c) \(f'(x) = \frac{1}{x^2+1} \cdot 2x = \frac{2x}{x^2+1}\)
4. Implícita: \(3x^2 + 3y^2y' = 6y + 6xy' \implies y'(3y^2-6x) = 6y-3x^2 \implies y' = \frac{6y-3x^2}{3y^2-6x} = \frac{2y-x^2}{y^2-2x}\)
5. Tangente: En \(x=1\), \(y=0\). \(f'(x)=3x^2-3 \implies m = 0\). Recta: \(y - 0 = 0(x-1) \implies y = 0\)
