📝 Soluciones - Ejercicios

1. \(\lambda_1 = 1, \lambda_2 = 3\)
2. \(p(\lambda) = \lambda^2 - 5\lambda - 2\), valores propios: \(\lambda = \frac{5 \pm \sqrt{33}}{2}\)
3. \(p(\lambda) = \lambda^2 + 3\lambda + 2 = (\lambda+1)(\lambda+2)\) → \(\lambda_1 = -1, \lambda_2 = -2\)
4. \(p(\lambda) = \lambda^3 - 6\lambda^2 + 10\lambda - 4 = (\lambda-2)(\lambda^2-4\lambda+2)\) → \(\lambda = 2, 2 \pm \sqrt{2}\)
5. Para \(\lambda=1\): \(v_1 = (1,-1)\). Para \(\lambda=3\): \(v_2 = (1,1)\).
6. Para \(\lambda_1 = \frac{5+\sqrt{33}}{2}\): \(v_1 = (2, \frac{1+\sqrt{33}}{4})\). Para \(\lambda_2 = \frac{5-\sqrt{33}}{2}\): \(v_2 = (2, \frac{1-\sqrt{33}}{4})\).
7. Para \(\lambda=-1\): \(v_1 = (1,-1)\). Para \(\lambda=-2\): \(v_2 = (1,-2)\).
8. \(P = \begin{pmatrix}1&1\\-1&1\end{pmatrix}\), \(D = \begin{pmatrix}1&0\\0&3\end{pmatrix}\)
9. \(P = \begin{pmatrix}2 & 2 \\ \frac{1+\sqrt{33}}{4} & \frac{1-\sqrt{33}}{4} \end{pmatrix}\), \(D = \begin{pmatrix}\frac{5+\sqrt{33}}{2} & 0 \\ 0 & \frac{5-\sqrt{33}}{2} \end{pmatrix}\)
10. \(P\) con columnas \((1,-1,1), (1,0,-1), (1,2,1)\) (vectores propios), \(D = \begin{pmatrix}2-\sqrt{2}&0&0\\0&2&0\\0&0&2+\sqrt{2}\end{pmatrix}\)
11. Para \(D = \text{diag}(d_1,\dots,d_n)\), \(D-\lambda I\) es diagonal con \(d_i-\lambda\) en la diagonal, el producto es \(\prod(d_i-\lambda)\), raíces \(d_i\).
12. Las matrices simétricas reales son diagonalizables ortogonalmente; los valores propios son reales.
13. Valores propios: \(-1, -2\) (ambos negativos) → sistema estable.
14. \(p(\lambda) = \lambda^2 + 2\lambda + 1 = (\lambda+1)^2\) → \(\lambda = -1\) (doble). Parte real negativa → estable.
15. \(\lambda_1 \approx 3.618, \lambda_2 \approx 0.382\). En PCA, la varianza se distribuye en estas direcciones.
