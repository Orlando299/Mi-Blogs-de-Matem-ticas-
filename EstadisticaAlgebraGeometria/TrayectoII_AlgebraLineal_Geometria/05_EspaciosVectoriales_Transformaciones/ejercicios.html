Ejercicios: Espacios Vectoriales y Transformaciones Lineales

MSc. Orlando Silva

Las soluciones están en soluciones.html (contraseña requerida).

1. Espacios vectoriales y subespacios

1. Verifica si el conjunto \(W = \{(x,y) \in \mathbb{R}^2 \mid x + y = 0\}\) es un subespacio de \(\mathbb{R}^2\).
2. Determina si \(W = \{(x,y,z) \in \mathbb{R}^3 \mid x = 2y\}\) es un subespacio de \(\mathbb{R}^3\).
3. ¿El conjunto de matrices \(2\times2\) con determinante cero forma un subespacio de \(\mathcal{M}_{2\times2}\)? Justifica.

2. Combinación lineal, dependencia e independencia lineal

4. Expresa el vector \((5,7)\) como combinación lineal de \(v_1 = (1,2)\) y \(v_2 = (3,4)\).
5. Determina si los vectores \((1,0,1)\), \((0,1,1)\), \((1,1,0)\) son linealmente independientes.
6. Encuentra una relación de dependencia lineal para los vectores \(v_1 = (1,2,3)\), \(v_2 = (2,4,6)\), \(v_3 = (3,6,9)\).

3. Base y dimensión

7. Encuentra una base para el subespacio \(W = \{(x,y,z) \in \mathbb{R}^3 \mid x + y + z = 0\}\).
8. Determina la dimensión del espacio de polinomios de grado menor o igual a 3 que tienen término independiente nulo.
9. ¿Cuál es la dimensión de \(\mathcal{M}_{2\times3}\)? Encuentra una base para este espacio.

4. Transformaciones lineales

10. Verifica si \(T: \mathbb{R}^2 \to \mathbb{R}^2\) definida por \(T(x,y) = (2x + y, x - y)\) es lineal.
11. Encuentra la matriz asociada a la transformación \(T(x,y,z) = (2x + y, z - x)\).
12. Dada \(T: \mathbb{R}^3 \to \mathbb{R}^2\) con \(T(x,y,z) = (x + y, y - z)\), encuentra el núcleo y la imagen.

5. Teorema de la dimensión (rango-nulidad)

13. Para la transformación \(T(x,y,z) = (x + y, y + z, x - z)\), calcula el rango y la nulidad. Verifica el teorema de la dimensión.

6. Aplicaciones

14. En un sistema de coordenadas, se aplica una rotación de \(45^\circ\) en el plano. Escribe la matriz de la transformación.
15. En el análisis de componentes simétricas de sistemas trifásicos, se usa la transformación de Fortescue. ¿Qué tipo de transformación lineal es?
