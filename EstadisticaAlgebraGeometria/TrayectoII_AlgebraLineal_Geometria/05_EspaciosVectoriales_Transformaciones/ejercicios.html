Ejercicios: Espacios Vectoriales y Transformaciones Lineales

MSc. Orlando Silva
Estadística, Álgebra Lineal y Geometría · PNF Electricidad · Trayecto II
Instrucciones. Resuelve cada ejercicio mostrando el procedimiento. Cuando se pida justificar, argumenta usando las definiciones y propiedades vistas en la teoría.

Dificultad: 🟢 Menor 🟡 Intermedio 🔴 Mayor

0. Preliminares: vectores en el plano y en el espacio

0.1 Módulo y normalización

  1. 🟢 Menor Dado \(\mathbf{v} = (3, -4)\), calcula su módulo \(\|\mathbf{v}\|\) y normaliza el vector (encuentra \(\hat{\mathbf{v}}\)).
  2. 🟢 Menor Dado \(\mathbf{v} = (1, 2, 2)\), calcula \(\|\mathbf{v}\|\) y normaliza el vector.

0.2 Operaciones con vectores

  1. 🟢 Menor Sean \(\mathbf{u} = (2, -1, 3)\) y \(\mathbf{v} = (-1, 4, 2)\). Calcula:
    a) \(\mathbf{u} + \mathbf{v}\)
    b) \(\mathbf{u} - \mathbf{v}\)
    c) \(3\mathbf{u}\)
    d) \(-2\mathbf{v}\)
  2. 🟡 Intermedio Dados \(\mathbf{a} = (1, 0, -2)\) y \(\mathbf{b} = (3, -1, 1)\), encuentra el vector \(\mathbf{x}\) tal que \[ 2\mathbf{x} - 3\mathbf{a} = \mathbf{b} \]

0.3 Producto escalar y ortogonalidad

  1. 🟡 Intermedio Verifica si los vectores \(\mathbf{u} = (2, 1)\) y \(\mathbf{v} = (-1, 2)\) son ortogonales.
  2. 🔴 Mayor Sean \(\mathbf{a} = (1, 2, 3)\) y \(\mathbf{b} = (2, -1, 1)\). Calcula \(\mathbf{a} \cdot \mathbf{b}\), \(\|\mathbf{a}\|\), \(\|\mathbf{b}\|\) y el ángulo \(\theta\) entre ellos.

1. Espacios vectoriales y subespacios

  1. 🟢 Menor Verifica si el conjunto \(W = \{(x, y) \in \mathbb{R}^2 \mid x + y = 0\}\) es un subespacio de \(\mathbb{R}^2\).
  2. 🟡 Intermedio Determina si \(W = \{(x, y, z) \in \mathbb{R}^3 \mid x = 2y\}\) es un subespacio de \(\mathbb{R}^3\).
  3. 🟡 Intermedio ¿El conjunto de matrices \(2 \times 2\) con determinante cero forma un subespacio de \(\mathcal{M}_{2,2}\)? Justifica.
  4. 🟢 Menor Verifica si \(W = \{(x, y, z) \in \mathbb{R}^3 \mid z = 0\}\) es un subespacio de \(\mathbb{R}^3\).
  5. 🟡 Intermedio Determina si \(W = \{(x, y) \in \mathbb{R}^2 \mid x \geq 0\}\) es un subespacio de \(\mathbb{R}^2\).
  6. 🟡 Intermedio ¿El conjunto de matrices \(2 \times 2\) simétricas (\(A^T = A\)) forma un subespacio de \(\mathcal{M}_{2,2}\)?
  7. 🔴 Mayor Sean \(W_1 = \{(x, y, z) \in \mathbb{R}^3 \mid x + y = 0\}\) y \(W_2 = \{(x, y, z) \in \mathbb{R}^3 \mid z = 0\}\). Encuentra \(W_1 \cap W_2\) y determina si es subespacio.

2. Combinación lineal, dependencia e independencia lineal

  1. 🟢 Menor Expresa el vector \((5, 7)\) como combinación lineal de \(v_1 = (1, 2)\) y \(v_2 = (3, 4)\).
  2. 🟡 Intermedio Determina si los vectores \((1, 0, 1)\), \((0, 1, 1)\), \((1, 1, 0)\) son linealmente independientes.
  3. 🟡 Intermedio Encuentra una relación de dependencia lineal para los vectores \(v_1 = (1, 2, 3)\), \(v_2 = (2, 4, 6)\), \(v_3 = (3, 6, 9)\).
  4. 🟢 Menor ¿Son linealmente independientes los vectores \((1, 2)\) y \((2, 4)\)? Justifica.
  5. 🟡 Intermedio Determina si los vectores \((1, 1, 0)\), \((0, 1, 1)\), \((1, 0, 1)\) son linealmente independientes usando el determinante.
  6. 🔴 Mayor Encuentra el valor de \(k\) para que los vectores \((1, 2, k)\), \((2, 1, 3)\), \((0, 1, 1)\) sean linealmente dependientes.
  7. 🔴 Mayor ¿Los polinomios \(p_1(x) = 1 + x\), \(p_2(x) = x + x^2\), \(p_3(x) = 1 + x^2\) son linealmente independientes en \(\mathcal{P}_2\)?

3. Base y dimensión

  1. 🟡 Intermedio Encuentra una base para el subespacio \(W = \{(x, y, z) \in \mathbb{R}^3 \mid x + y + z = 0\}\).
  2. 🟡 Intermedio Determina la dimensión del espacio de polinomios de grado menor o igual a 3 que tienen término independiente nulo.
  3. 🟢 Menor ¿Cuál es la dimensión de \(\mathcal{M}_{2,3}\)? Encuentra una base para este espacio.
  4. 🟢 Menor Encuentra la dimensión y una base del subespacio \(W = \{(x, y, z) \in \mathbb{R}^3 \mid x = 0\}\).
  5. 🟡 Intermedio Encuentra las coordenadas del vector \(\mathbf{v} = (4, 2)\) respecto a la base \(B = \{(1, 1), (1, -1)\}\).
  6. 🟡 Intermedio Encuentra una base para el subespacio \(W = \{(x, y, z, w) \in \mathbb{R}^4 \mid x - y = 0,\ z + w = 0\}\) y determina su dimensión.
  7. 🔴 Mayor Determina la dimensión y una base del espacio generado por \(\{(1, 2, 3), (2, 4, 6), (1, 0, 1)\}\).

4. Transformaciones lineales

  1. 🟢 Menor Verifica si \(T: \mathbb{R}^2 \to \mathbb{R}^2\) definida por \(T(x, y) = (2x + y, x - y)\) es lineal.
  2. 🟡 Intermedio Encuentra la matriz asociada a la transformación \(T(x, y, z) = (2x + y, z - x)\).
  3. 🟡 Intermedio Dada \(T: \mathbb{R}^3 \to \mathbb{R}^2\) con \(T(x, y, z) = (x + y, y - z)\), encuentra el núcleo y la imagen.
  4. 🟢 Menor Verifica si \(T: \mathbb{R} \to \mathbb{R}\) con \(T(x) = 3x\) es una transformación lineal.
  5. 🟡 Intermedio Verifica si \(T(x, y) = (x^2, y)\) es una transformación lineal.
  6. 🟡 Intermedio Encuentra la matriz asociada a la rotación de \(90°\) en el plano \(\mathbb{R}^2\).
  7. 🔴 Mayor Dada la transformación \(T(x, y) = (3x - y, x + 2y)\), encuentra su matriz asociada y verifica que \(T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})\) para \(\mathbf{u} = (1, 2)\), \(\mathbf{v} = (-1, 1)\).

5. Núcleo e imagen

  1. 🟡 Intermedio Dada \(T: \mathbb{R}^3 \to \mathbb{R}^2\) con \(T(x, y, z) = (x + y,\ y - z)\), encuentra el núcleo y la imagen (repaso).
  2. 🟡 Intermedio Encuentra el núcleo e imagen de la transformación \(T(x, y, z) = (x - z,\ y + z)\).
  3. 🔴 Mayor Para \(T: \mathbb{R}^3 \to \mathbb{R}^3\) definida por \(T(x, y, z) = (x + y, y + z, x + 2y + z)\), encuentra el núcleo, la imagen y verifica el teorema de la dimensión.
  4. 🔴 Mayor Sea \(T: \mathbb{R}^4 \to \mathbb{R}^3\), \(T(x, y, z, w) = (x + y + z + w,\ x - y,\ z - w)\). Encuentra el núcleo y su dimensión.

6. Teorema de la dimensión (rango-nulidad)

  1. 🟡 Intermedio Para la transformación \(T(x, y, z) = (x + y,\ y + z,\ x - z)\), calcula el rango y la nulidad. Verifica el teorema de la dimensión.
  2. 🔴 Mayor Sea \(T: \mathbb{R}^4 \to \mathbb{R}^2\) definida por \(T(x, y, z, w) = (x + y + z + w,\ x - y + z - w)\). Calcula el rango, la nulidad y verifica el teorema de la dimensión.
  3. 🔴 Mayor Para la transformación \(T(x, y, z) = (x + 2y - z,\ 2x + 4y - 2z)\), encuentra el rango y la nulidad sin resolver todo el sistema, usando el teorema de la dimensión.

7. Aplicaciones

  1. 🟡 Intermedio En un sistema de coordenadas, se aplica una rotación de \(45°\) en el plano. Escribe la matriz de la transformación.
  2. 🔴 Mayor En el análisis de componentes simétricas de sistemas trifásicos, se usa la transformación de Fortescue. ¿Qué tipo de transformación lineal es?
  3. 🟡 Intermedio Dado el sistema \(A\mathbf{x} = \mathbf{b}\) con \(A = \begin{pmatrix} 1 & 2 \\ 3 & 6 \end{pmatrix}\) y \(\mathbf{b} = (1, 3)\), encuentra el espacio nulo de \(A\) y discute si el sistema tiene solución única, infinitas o ninguna.
  4. 🟡 Intermedio La transformación de Clarke (abc → αβ0) en máquinas eléctricas está dada por la matriz \[ C = \frac{2}{3}\begin{pmatrix} 1 & -\tfrac12 & -\tfrac12 \\ 0 & \tfrac{\sqrt{3}}{2} & -\tfrac{\sqrt{3}}{2} \\ \tfrac12 & \tfrac12 & \tfrac12 \end{pmatrix} \] Verifica si \(C\) es invertible y calcula el rango.
  5. 🔴 Mayor Un sistema de tres corrientes trifásicas \(I_a, I_b, I_c\) con \(I_a + I_b + I_c = 0\) se puede representar como un vector en un subespacio de \(\mathbb{R}^3\). Encuentra una base para este subespacio y su dimensión.
Recuerda: antes de aplicar cualquier método, identifica primero qué se pide: ¿un subespacio?, ¿una base?, ¿el núcleo?, ¿una matriz asociada? Cada tipo de problema tiene su propio procedimiento.
